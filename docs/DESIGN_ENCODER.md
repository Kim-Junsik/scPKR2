## 0. 왜 이 설계인가

생물학 지식을 세포 쪽에 넣은 실험은 모두 무작위와 구분되지 않았다.

| 자리 | 넣은 지식 | 결과 (FINDINGS) |
|---|---|---|
| 세포 인코더 (관측 좌표) | KEGG 유전자 묶음 | 무작위 묶음과 같음 (21) |
| 생성자 연결 구조 | KEGG 공유 유전자 그래프 | 섞은 그래프가 더 나음 (22) |
| 생성자 연결 구조 | KEGG 지도 링크 | 섞은 그래프가 더 나음 (23) |
| 생성자 연결 구조 | KEGG 뼈대 + 벌점 잔차 | 그래프 밖 비율 2/12, 불통과 (24) |
| 학습 신호 (OT 짝짓기) | — | 짝짓기를 무작위로 해도 +0.013, 지식이 전달될 길이 좁음 (25) |

공통 원인은 이렇게 본다. 세포에 대해서는 데이터(수만~수십만 세포)가 이미 충분하므로 세포 쪽 지식은 더할
것이 없다. 반면 **교란에 대한 데이터는 부족할 수 있다.**

| 데이터셋 | 교란 데이터 |
|---|---|
| Norman (Table 1) | 모든 단일 교란을 관측. 충분 |
| ComboSciPlex (Table 3) | 약물 17개 중 11개는 단독 데이터 없음, 일부는 조건 1개뿐. 부족 |
| VCC 2025 H1 | 테스트 유전자 100개는 학습에 한 번도 없음. **없음** |

데이터가 없는 교란은 지식 없이는 생성자를 만들 수 없다. 그래서 이 설계는 지식을 **교란 쪽**, 즉 교란 하나를
받아 그 생성자를 만드는 부분에 넣는다.

## 1. 모델

지금의 교란 → 생성자 부분은 조회표다. 교란마다 자기 계수와 고유 행렬을 따로 학습한다.

```
지금:  A_a = U diag(c_a) V + P_a Q_a            c_a ∈ R^32, P_a Q_a: 교란마다 자유 파라미터
```

이것을 지식 기반 인코더로 바꾼다.

```
c_a = c̄ + E k_a + δ_a                           k_a: 교란 a의 지식 벡터 (고정, 학습 안 함)
A_a = U diag(c_a) V + P_a Q_a                    c̄: 공유 계수, E: 지식 → 계수 (학습)
                                                 δ_a, P_a Q_a: 교란별 보정 (데이터가 있을 때만)
```

- **처음 보는 교란** (VCC 테스트): `δ_a = 0`, `P_a Q_a = 0`. 생성자는 지식만으로 만든다:
  `A_a = U diag(c̄ + E k_a) V`.
- **데이터가 충분한 교란**: 교란별 보정이 데이터로 맞춰지므로 지금의 조회표 모델에 가까워진다.
- **교란 드롭아웃.** 학습의 각 단계에서 교란마다 확률 p로 교란별 보정(`δ_a`, `P_a Q_a`)을 0으로 둔다.
  보정이 늘 있으면 `E`는 할 일이 없어서, 처음 보는 교란에 쓸 지식 경로가 학습되지 않는다. 드롭아웃은
  학습 중에 "처음 보는 교란" 상황을 흉내 내어 지식 경로가 혼자서도 생성자를 만들게 한다. p는 검증
  분할에서 고른다(H0).
- 초기값: `c̄ = 1`(지금과 같음), `E = 0`, `δ_a = 0`. 학습 전 모델은 지금과 같다.
- **나머지는 2단계 D 설정 그대로다**: 조밀 생성자, ZCA 백색화, 관측 공간 손실 없음, 행렬 지수 합성,
  디코더, 출력식. FINDINGS 24의 성긴 + 잔차 구조는 아직 사후 관찰이라 여기서 섞지 않는다. 이 설계가
  통과한 뒤 따로 합친다.

## 2. 지식

### 2.1 유전자: STRING 단백질 상호작용의 스펙트럼 임베딩

- 출처: `data/networks/string_links.txt.gz`, `string_info.txt.gz` (이미 있음, 추가 다운로드 없음).
- 그래프: combined_score ≥ 700 (높은 신뢰도). 간선 173,038개, 간선이 있는 단백질 10,746개.
- `k_a`: 정규화 인접행렬의 상위 64개 고유벡터(자명한 것 제외)에서 유전자 a의 행. 각 차원은 표준화한다.
  결정적이고(같은 입력이면 같은 결과), 학습 데이터를 보지 않는다.
- STRING에 없는 유전자는 `k_a = 0`이다. 그러면 생성자는 `c̄`, 즉 "평균적인 교란"이 된다.
  이것이 지식이 없을 때의 자연스러운 대체값이다.

| | 학습 | 검증 | 테스트 |
|---|---|---|---|
| VCC 유전자 (STRING ≥ 700에 있음) | 128 / 150 | 44 / 50 | 81 / 100 |
| Norman 표적 | 73 / 101 | | |

고르지 않은 대안: 학습 교란의 계수를 STRING 이웃으로 평균 내는 그래프 전파(GEARS 방식). 스펙트럼
임베딩 + 선형 사상이 더 단순하고, 본 교란과 처음 보는 교란을 같은 식으로 다루며, 대조군(임베딩 섞기)을
만들기 쉽다.

### 2.2 약물: 작용 기전 (ComboSciPlex)

- 출처: ComboSciPlex 원본의 `pathway1`, `pathway2` 주석. 6개 기전(HDAC 4, Sirtuin 4, "EGFR" 4,
  단백질 접힘 2, DNA 손상 2, 세포주기 1).
- `k_d`: 기전 원핫 벡터. 같은 기전의 약물은 `E k_d`(공통 성분)를 공유한다.
- **주석이 거칠다.** 키나아제 억제제 4개가 모두 "EGFR inhibitor"이고, SRT 계열(SIRT1 활성제)이
  "Sirtuin inhibitor"로 적혀 있다. 고치지 않고 데이터에 있는 그대로 쓴다. 손으로 고치면 그 자체가
  검증 데이터를 본 선택이 될 수 있다.

## 4. 비교 실험

| 실험 | 지식 | 대상 |
|---|---|---|
| **E** | 진짜 지식 (STRING 임베딩 / 기전) | 주 모델 |
| S | 섞은 지식: 지식 벡터를 교란끼리 무작위로 바꿈, 시드마다 다른 순열 | 대조군 |
| N | 지식 없음: `k_a = 0` (처음 보는 교란 → 평균 교란) | 대조군 |
| B0 | 평균 기준선: 학습 교란들의 평균 반응을 모든 테스트 교란에 예측 (닫힌 형태, 학습 없음) | 기준선 |
| D | 지금의 조회표 모델 (Norman, ComboSciPlex만; 처음 보는 교란을 예측할 수 없음) | 기준선 |

S의 순열: 유전자는 STRING에 있는 유전자끼리만 섞는다(없는 유전자의 0 벡터는 그대로). 약물은 기전 라벨을
약물끼리 섞되 기전별 약물 수를 유지한다.

## 5. 가설과 판정 조건

**H0. 고르는 것은 검증 분할에서만.**
- VCC: 교란 드롭아웃 p ∈ {0.25, 0.5, 0.75} × 학습 길이 ∈ {100, 250} 에폭, E와 S 각각 시드 0 (run 12개).
  **E와 S의 검증 L2 평균이 가장 낮은 조합**을 고른다. E만 보고 고르면 E에 유리하다.
- ComboSciPlex: p ∈ {0.25, 0.5, 0.75} × 학습 길이 ∈ {1000, 2500} 에폭, M과 MP 각각 시드 0, 기존

**5.1 보조 분석 (테스트를 보기 전, 2026-10-21에 선언).** ComboSciPlex 테스트에서 드롭아웃 0.5로도 M과
MP를 시드 3개씩 돌린다(`combo-dose`, 2500 에폭). C1의 판정은 바꾸지 않는다. 이것은 "모델이 지식에
기대야 할 때 진짜 지식과 섞은 지식의 차이"를 보는 기술 통계로만 보고한다. 같은 기준(MP − M 평균 차,
7개 조건 중 M이 낮은 수)을 적되 통과·불통과로 부르지 않는다.

> **판정 (2026-10-22, FINDINGS 26절).** V1 규칙상 통과(p 0.0035, 66/100), 단 E의 평균 L2가 S보다 0.31 높고 지식 없는 N보다 0.72 높다. V2 불통과. N1 통과(nE 1.6365, D 1.6852). C1은 학습 중.

**5.2 N2: Norman의 향상은 지식 때문인가 (N1의 결과를 본 뒤, 대조군을 돌리기 전에 선언, 2026-10-22).**
N1에서 nE(1.6365)가 D(1.6852)보다 0.049 나았다. 인코더 run은 모두 교란 드롭아웃으로 학습하므로, 이
향상이 지식 때문인지 드롭아웃의 정규화 때문인지 가를 수 없다. fold 3에서 같은 설정으로 S(섞은 STRING)와
N(지식 없음)을 시드 3개씩 돌린다(`norman-controls`, 드롭아웃 0.25, 250 에폭).

- nS와 nN의 L2 평균이 **둘 다** nE보다 0.02 넘게 높으면: 향상은 지식 때문이다.
- 그렇지 않으면: 향상은 지식이 아닌 다른 것(드롭아웃 등) 때문이며, 지식의 기여로 쓰지 않는다.

fold 3은 개발에 반복해서 쓴 fold이고 N1의 결과를 본 뒤의 선언이므로, 통과해도 판정 fold(0, 1, 2, 4)에서
다시 확인하기 전까지는 예비 결과로만 쓴다.

**5.3 ComboSciPlex의 지식 없음 N (C1의 결과를 본 뒤, 돌리기 전에 선언, 2026-10-22).**
C1에서 섞은 기전 MP(1.5884)가 진짜 기전 M(1.8813)보다 7/7 조건에서 나았고, scDFM 발표 값(1.6567)보다도
낮았다. 섞은 지식은 방법이 될 수 없으므로 그 출처를 가린다. 같은 설정(드롭아웃 0.25, 2500 에폭)으로 지식
없음 N을 시드 3개 돌려(`combo-zero`) D, M, MP와 나란히 놓는다. 판정이 아니라 귀속(attribution)이며, 시드
간 표준편차가 0.15~0.20이라 시드 3개로는 0.1보다 작은 차이를 가를 수 없다는 것을 함께 적는다.

- N이 MP만큼 낮다(차이 0.1 이내): 향상은 약물을 묶는 방식이 아니라 공유 성분 c̄와 교란 드롭아웃에서 온다.
  교란 드롭아웃은 생물학 주장 없이 쓸 수 있는 방법론 요소가 된다(판정 fold에서의 확인 전까지는 예비).
- N이 D만큼 높다: 향상은 무작위로라도 약물을 묶어 공유시키는 것에서 온다. 진짜 기전 묶음이 그보다 나쁘다는
  것은 데이터 주석의 묶음이 이 데이터에 맞지 않는다는 뜻이다.
- 어느 쪽이든 C1의 판정은 바뀌지 않는다.

> **N2 판정 (2026-10-22, FINDINGS 28절): 통과(예비).** nE 1.6365, nS 1.6862, nN 1.7098.

**5.4 N3: Norman 판정 fold에서의 확인 (N2의 결과를 본 뒤, 돌리기 전에 선언, 2026-10-22).**
N2는 fold 3에서 정한 사후 기준이었다. fold 0, 1, 2, 4 × 시드 3개에서 E(STRING), S(섞음), N(지식 없음)을 같은
설정(드롭아웃 0.25, 250 에폭)으로 돌린다(`norman-confirm`, run 36개). D는 기존 `s2fin` run을 쓴다.

- **N3 통과:** 같은 fold·시드의 12쌍 중 **10쌍 이상에서 E가 S보다 낮고**(한쪽 부호 검정 p = 0.019), **그리고**
  E의 평균 L2가 N보다 0.02 넘게 낮다.
- 통과하면 논문에 "STRING 지식으로 교란 생성자를 만들면, 데이터가 충분한 Norman에서도 조합 예측이 좋아진다"고
  쓸 수 있다. 섞은 지식과 지식 없음이 대조군이다.
- 보고만: E와 D의 차이(정확도 향상의 크기), fold별 표.

**V1. 지식이 기여한다 (VCC, 1차 판정).**
테스트 유전자 100개 각각의 L2(예측 평균과 실제 평균의 거리, 18,080개 유전자, 정규화 + log1p, 시드 3개
평균)를 E와 S에서 짝지어 비교한다. **한쪽 Wilcoxon 부호 순위 검정 p < 0.01이고 E의 중앙 개선이 0보다
크면 통과.** STRING에 있는 81개와 없는 19개를 나눠서도 보고한다(없는 19개는 두 실험이 같은 생성자를 쓰므로
차이가 0이어야 한다 — 구현 확인용이기도 하다).

**V2. 기준선을 넘는다 (VCC).**
같은 검정으로 E가 B0를 넘어야 한다. 처음 보는 교란 예측에서는 단순 기준선이 강하다고 알려져 있다
(Ahlmann-Eltze 등, Nature Methods 2025). V1이 통과해도 V2가 실패하면 "지식이 섞은 지식보다는 낫지만
쓸모 있는 예측은 아니다"로 보고한다.

**V3. 공식 지표 (보고만).** VCC 2025의 공식 채점(cell-eval의 VCC 지표)을 E, S, N, B0에 대해 함께 적는다.

**C1. 약물 기전 (ComboSciPlex, 보조).**
M과 MP의 테스트 L2 평균 차이(MP − M)가 0.02를 넘고, **7개 조건 중 6개 이상에서 M이 낮으면** 통과한다
(조건별 L2는 시드 평균). 검정력이 낮다는 것을 함께 적는다. Table 3의 여섯 열은 발표 프로토콜로 함께 잰다.

**N1. 해가 없다 (Norman, fold 3).**
E(STRING) ≤ D + 0.02 (D = 1.6852, 시드 3개). 데이터가 충분할 때 지식 인코더가 정확도를 깎으면 안 된다.

## 6. 판정에 따른 길

| V1 | V2 | 다음 |
|---|---|---|
| 통과 | 통과 | 지식 인코더를 주 모델에 넣는다. 논문의 생물학 주장은 "처음 보는 교란에서 지식이 필수이고, 섞은 지식과 기준선을 넘는다" |
| 통과 | 불통과 | 지식은 섞은 것보다 낫지만 기준선을 못 넘는다. 그대로 보고하고 방향은 저자가 정한다 |
| 불통과 | — | 교란 쪽 지식도 기여하지 않는다. 생물학 지식은 해석(경로 좌표)으로만 쓴다 |

C1과 N1은 V1의 결론을 보강하거나 제한한다. 이 셋을 합친 서사는 "지식은 데이터가 부족한 만큼 돕는다"이다
(Norman: 충분 → 차이 없음, ComboSciPlex: 부족 → 약간, VCC: 없음 → 필수). 이 서사는 세 판정이 실제로 그렇게
나올 때만 쓴다.

## 7. 구조가 보장하는 것 (테스트)

| | 성질 |

| E6 | 2단계의 G1~G7 (양수성, 대조군 정확성, 순서 불변 등) 유지 |

## 9. 말할 수 있는 것과 없는 것

**말할 수 있는 것 (V1, V2 통과 시)**
- 처음 보는 유전자 교란에서, 단백질 상호작용 지식으로 만든 생성자가 같은 지식을 섞은 것과 평균 기준선을
  넘는다.
- 생성자 조합 방식(행렬 지수)과 지식 인코더가 한 모델 안에서 함께 작동한다.

**말할 수 없는 것**
- V1이 실패하면 "생물학 지식이 예측을 돕는다".
- STRING 임베딩이 "최선의 지식 표현"이라는 것. 하나의 표현을 시험할 뿐이다.
- C1만 통과하고 V1이 실패하면 일반적인 지식의 기여. ComboSciPlex는 테스트 7개라 단독 근거가 될 수 없다.
- 약물 기전 주석의 정확성. 데이터의 주석을 그대로 썼다.

## 10. 이 문서가 정하지 않는 것

- 지식 표현의 다른 선택: GO, CollecTRI 조절 대상, 언어모델 유전자 임베딩. V1이 통과한 뒤 비교한다.
- 약물 표적 유전자를 STRING 임베딩에 연결하는 판(약물 → 표적 → 임베딩). 표적 데이터를 받아야 한다.
- 성긴 뼈대 + 잔차 생성자(FINDINGS 24)와의 결합.
- Norman에서 유전자를 통째로 빼는 분할(교란 수준의 데이터 부족). VCC가 그 역할을 맡는다.
- VCC 2026 대회 참가. 과제(처음 보는 세포주)가 다르고 일정이 맞지 않는다.
