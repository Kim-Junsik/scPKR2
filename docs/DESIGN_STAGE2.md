# scPKR2 2단계 설계 — 양수 공간의 Koopman 생성자 모델

이 문서는 **짓기 전에** 쓴다. 각 주장마다 **무엇이 관측되면 철회하는지**를 미리 적는다.
1단계 설계는 [DESIGN.md](DESIGN.md), 측정 기록은 [FINDINGS.md](FINDINGS.md)에 있다.

---

## 0. 왜 2단계인가

1단계 모델은 성능 기준을 넘었다. norman additive, 5 fold × 시드 3개, 발표 표와 같은
프로토콜(FINDINGS 17절):

| | L2 | MSE | MAE | DE-Spearman | Pearson Δ | DS |
|---|---|---|---|---|---|---|
| scDFM | 1.7043 | 0.00315 | 0.02155 | 0.5705 | 0.8853 | 0.9737 |
| 1단계 | 1.6439 | 0.00357 | 0.02081 | 0.6630 | 0.8949 | 0.9431 |

그러나 구조는 **임베딩의 합을 MLP에 넣는 것**이 전부다. 효과가 확인된 부품은 출력 형태
`mu = x exp(u) + softplus(v)` 하나이고, `u`와 `v`를 만드는 쪽에는 방법론이라 부를 것이 없다.
**이 상태로는 논문의 모델이 아니다.**

2단계는 `u`, `v`를 만드는 MLP를 **구조를 가진 연산자**로 바꾼다. 1단계는 버리지 않는다 —
넘어야 할 기준선이자, 구조가 값어치를 내는지 재는 대조군이다.

---

## 1. 모델

```
p      = [ Phi(x) ; 1 ]                       관측 좌표 K개 + 상수 1개
A_a    = U diag(c_a) V + P_a Q_a              교란 a의 생성자, (K+1) x (K+1), 마지막 행은 0
B_S    = sum_{a in S} A_a                     동시 교란 = 생성자의 중첩
dp     = (exp(B_S) - I) p                     관측 좌표의 이동, 닫힌 형태
u      = W_u dp                               유전자별 로그 게인
v      = v0 + W_v dp                          유전자별 켜짐 항
mu     = x * exp(u) + softplus(v)             세포별 예측
```

학습되는 것은 생성자 `A_a`(공유 모드 `U, V`, 교란별 계수 `c_a`, 저계수 고유 부분
`P_a Q_a`)와 읽기 행렬 `W_u, W_v`, 유전자별 상수 `v0`다. `Phi`는 고정이다.

1단계와 다른 곳은 가운데 세 줄뿐이다. **MLP가 사라지고, 교란이 무엇을 하는지가 생성자
하나로 표현된다.**

---

## 2. 각 부품의 근거

### 2.1 교란 = 관측 좌표 위의 선형 생성자

Koopman 관점에서는 비선형 변화도 좋은 관측량 위에서는 선형으로 움직인다. 교란 `a`를 그
선형 운동의 생성자 `A_a`로 둔다. 효과는 `exp(A_a)`이고, **선형이므로 적분기 없이 행렬 지수
하나로 정확히 계산된다.**

### 2.2 동시 교란 = 생성자의 합, 그리고 상호작용은 지수 사상에서 나온다

두 교란이 동시에 작용하면 두 생성자가 중첩된다: `B_S = A_a + A_b`. 이것은 고른 것이 아니라
동시에 작용하는 두 벡터장의 표준적인 합성이다.

여기서 비가법성이 **추가 파라미터 없이** 나온다.

```
exp(A + B) - I  =  (A + B)  +  (1/2)(A + B)^2  +  ...
               =  [exp(A) - I] + [exp(B) - I]  +  (1/2)(AB + BA)  +  O(3)
```

각자의 효과를 더한 것과의 차이가 **반교환자 `(AB + BA)/2`**로 시작한다. 교환 대칭이므로
순서가 없는 동시 교란에 맞는 형태다. v2에서는 이 항을 따로 만들어 넣었다. 여기서는
**생성자를 더하고 지수를 취하는 것만으로 따라 나온다.**

### 2.3 귀무모형이 곱셈형이다

`u`가 로그 게인이므로, 생성자들이 서로 간섭하지 않으면(교환하고 작으면) `u_S = u_a + u_b`,
즉 **fold change가 곱해진다.** 유전적 상호작용 연구에서 이중 교란의 기대값을 로그 공간의
합(곱셈 모형)으로 두는 것과 같은 귀무모형이다. 이 모델에서 상호작용은 그 귀무모형으로부터의
이탈이고, 그 이탈의 선두 항이 2.2의 반교환자다.

1단계의 측정이 이 선택을 뒷받침한다 — 곱셈형 출력은 음수를 낼 수 없고, 대조군 세포의 0
구조를 물려받아 세포 수준 지표에서 이긴다(FINDINGS 13절).

### 2.4 상수 관측량이 반드시 있어야 한다

`Phi(x)`는 학습 세포에서 평균 0으로 표준화되어 있다. 상수항이 없으면 평균적인 세포에서
`Phi(x) = 0`이므로 `dp = 0`, 즉 **평균 세포에는 어떤 교란도 효과가 없다**는 모델이 된다.
교란의 평균 효과를 표현할 길이 없다.

그래서 좌표에 상수 1을 더한다. 생성자의 마지막 행을 0으로 고정하면 상수는 흐름 아래에서
1로 남고, `exp(B_S)`는 `Phi(x) -> M Phi(x) + b`인 **아핀 변환**이 된다. `b`가 평균 효과,
`M`이 세포 상태에 따른 차이다. v2에서는 평균 효과를 ridge가 맡았기 때문에 이것이 필요
없었다.

### 2.5 공유 모드

ComboSciPlex는 약 17개 중 13개가 단독으로 관측되지 않고 학습 조건이 25개다. 교란마다
`(K+1)^2`짜리 자유 행렬을 주면 과적합한다 — 1단계에서 교란별 자유 벡터를 주었을 때 학습
손실은 절반이 되고 테스트 L2는 1.68에서 2.49로 나빠졌다(FINDINGS 2절). 그래서 생성자의
대부분은 모든 교란이 공유하는 모드 `U, V`에서 오고, 교란은 그 모드들의 계수 `c_a`와 작은
고유 부분만 갖는다.

## 3. 구조가 보장하는 것

짓는 즉시 테스트로 고정한다. 하나라도 깨지면 구현이 틀린 것이다.

| | 성질 | 이유 |
|---|---|---|
| G1 | `mu >= 0` | 양수 × 양수 + 양수 |
| G2 | 교란이 없으면 `mu = x + softplus(v0)` | `B = 0`이면 `dp = 0` |
| G3 | 조합의 순서와 무관 | 합은 교환적이다 |
| G4 | 쌍으로 색인된 파라미터가 없다 | 본 적 없는 조합을 표현할 수 있는 조건 |
| G5 | 학습 전 모델은 대조군이다 | `W_u = W_v = 0`에서 출발. `A_a`는 작은 난수 |
| G6 | 상수 좌표는 흐름 아래에서 1로 남는다 | 생성자의 마지막 행이 0 |
| G7 | 교환하는 두 생성자에 대해 `exp(A+B) = exp(A) exp(B)` | 귀무모형이 정확히 곱셈형 |

G5에서 `A_a`를 0으로 두지 않는 이유: `W`가 0일 때 `W`의 기울기는 `dp`에 비례하고, `A_a`가
0이면 `dp = 0`이라 아무것도 움직이지 않는다.

## 4. 학습

1단계와 같다. OT 결합으로 대조군 세포와 처리군 세포를 짝짓고, 손실은

- 유전자 공간의 집단 평균 손실 (가중치 10),
- 켜짐/크기의 hurdle 우도,

그리고 2단계에서 다시 켜지는 **관측 공간의 두 항**이다.

- flow matching: `|| B_S p_t - (p1 - p0) ||^2`
- 끝점: `|| exp(B_S) p0 - p1 ||^2`

이 두 항이 생성자에게 **"관측 좌표에서 처리군이 있는 곳으로 옮겨라"**를 직접 가르친다.
이것이 없으면 연산자 경로는 그냥 병목 특징일 뿐이고 Koopman이라는 이름에 내용이 없다.
있고 없고의 차이를 7절에서 잰다.

학습 길이는 1단계의 500 에폭을 그대로 가져오지 않는다. 구조가 다르면 최적 길이가 다르다.
검증 분할에서 **각자 스케줄을 끝까지 도는 독립 run**으로 고른다(FINDINGS 3절의 교훈).

## 6. 가설과 반증 조건

**S1. 생성자 경로가 MLP만큼 맞힌다.**
fold 3, 시드 3개에서 L2가 1.7519 + 0.02 = **1.772를 넘으면** 구조가 정확도를 깎는 것이다.
그 경우 MLP를 잔차로 남긴 혼합형(`u = W_u dp + MLP`)을 한 번 시험한다. 혼합형에서 연산자
항이 MLP 단독보다 **0.02 이상 벌지 못하면 연산자는 장식이다. 2단계를 논문의 방법으로 쓰지
않는다.**

**S2. 지수 사상의 2차 이상 항이 값어치를 낸다.**
선형화한 모델(`dp = B_S p`, 지수 없음)과의 차이가 **0.01 이하면** "상호작용이 지수 사상에서
나온다"는 주장을 철회한다. 그때 모델은 곱셈형 귀무모형일 뿐이다.

**S3. 관측 공간의 손실이 값어치를 낸다.**
flow matching·끝점 항을 뺀 것과의 차이가 **0.01 이하면** 그 항들을 빼고, 연산자 경로를
"관측량 위의 동역학"이라 부르지 않는다.

**S4. 생물학적 좌표가 하중을 받는다.**
KEGG 좌표를 **같은 크기의 무작위 유전자 묶음**으로 바꾼 것과의 차이가 시드 잡음(0.02)
안이면, 경로 사전지식이 기여한다고 주장하지 않는다. v2에서는 이 대조에서 차이가 없었다.
좌표로 쓰는 것은 유지할 수 있지만 대조 결과를 함께 보고한다.

**S5. `mu < 0`이 하나라도 나오면** 구현이 틀린 것이다.

**S6. 5 fold에서 1단계보다 나빠지지 않는다.**
발표 프로토콜의 Table 1에서 L2가 1단계(1.6439)보다 나쁘거나, 지금 scDFM을 이기는 네 열
(L2, MAE, DE-Spearman, Pearson Δ) 중 하나라도 잃으면, **더 나은 모델은 1단계**이고 2단계는
그 위의 개선이 아니다.

## 7. 비교 실험

fold 3, 시드 3개씩. 이 표가 통과하면 그대로 논문의 ablation이 된다.

| 실험 | 바꾸는 것 | 답하는 질문 |
|---|---|---|
| A | 1단계 MLP (기준) | — |
| B | 생성자 모델 (1절 그대로) | S1 |
| C | B에서 지수를 선형화 | S2 |
| D | B에서 관측 공간 손실 제거 | S3 |
| E | B에서 KEGG를 무작위 묶음으로 | S4 |
| F | B + 명시적 반교환자 계수 `kappa` | 지수 사상이 주는 것 이상이 필요한가 |
| G | B에서 상수 좌표 제거 | 2.4의 주장 확인 |
| H | B에서 공유 모드 제거 (교란별 자유 저계수) | 2.5의 주장 확인 |

B가 S1을 통과해야 C~H가 의미를 갖는다. **B부터 돌리고, 통과하면 나머지를 돌린다.**

## 9. 통과했을 때 말할 수 있는 것과 없는 것

**말할 수 있는 것 (S1~S3, S6이 통과하면)**

- 교란을 관측 좌표 위의 생성자로 표현하고, 조합을 생성자의 중첩으로 다루는 모델.
- 조합의 상호작용이 지수 사상의 2차 항(반교환자)으로 **유도되어** 나오며, 그 항을 뺀
  모델보다 낫다는 측정.
- 귀무모형이 곱셈형이고 출력이 구조적으로 양수라서, 추가 샘플링 없이 세포 수준 지표가 맞는다.
- 닫힌 형태 기준선(ridge)을 모델 안에 두지 않고 그것을 넘는다.

**말할 수 없는 것**

- S4가 통과하지 않으면 "생물학적 사전지식이 기여한다"고 쓸 수 없다.
- S2가 통과하지 않으면 "상호작용을 모델링한다"고 쓸 수 없다.
- Table 3(ComboSciPlex)에서 지금 L2로 지고 있다. 2단계가 그것을 고친다는 근거는 아직 없다.

## 10. 이 문서가 정하지 않는 것

- 공유 모드의 수와 고유 부분의 계수. v2의 값(32, 4)에서 시작해 측정으로 정한다.
- 읽기 행렬을 조밀하게 둘지 KEGG 구조로 제한할지. S4의 일부로 잰다.
- 검출 확률 `q`를 무엇에서 읽을지. 보고하는 soft 게이트에서는 쓰이지 않고 학습의 우도
  항에만 들어가므로, `dp`의 선형 읽기로 시작한다.
- 혼합형의 구체적 형태. S1에 걸렸을 때만 필요하다.
