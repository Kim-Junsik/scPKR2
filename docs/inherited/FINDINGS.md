# 측정된 것들 — 다음 프로젝트로 가져갈 기록

이 프로젝트는 **생물학적 사전지식을 딥러닝 모델에 하중이 걸리도록 녹이는 것**을 목표로
했고, 그 목표에서 실패했다. 이 문서는 그 과정에서 **측정된** 것들만 모은다. 모델의
설명은 [MODEL.md](MODEL.md), 설계와 사전 등록한 주장들은 [DESIGN.md](DESIGN.md)에 있다.

여기 있는 숫자는 전부 **검증 분할에서** 측정했다. 보고용 테스트 집합은 이 저장소에서
한 번도 채점하지 않았다.

---

## 1. 분야에 대한 발견 — 닫힌 형태 ridge가 발표된 딥러닝 모델들을 절반의 표에서 이긴다

`scripts/baseline_l2.py`, 5 fold, 보고된 프로토콜(테스트 부분집합의 scanpy HVG 1,000개,
soft gate). Control L2가 논문 값과 0.2~2.5% 안에서 일치하므로 축척이 검증되었다.

| | ridge_additive | scDFM | scPKFM(v1) |
|---|---|---|---|
| Table 1 Norman additive | **1.669** | 1.704 | 1.957 |
| Table 2 Single | **1.416** | 1.619 | 1.754 |
| Table 2 Double | 2.251 | **2.031** | 2.375 |
| Table 3 ComboSciPlex | 1.858 | **1.657** | 2.138 |

`ridge_additive`는 **교란별 효과 벡터를 학습 조건으로 ridge 적합해 `w_A + w_B`를 내는
것이 전부**다. 상호작용 항도, 신경망도, flow도 없다.

**어떤 섭동 예측 논문이든 이 행을 실어야 한다.** v1의 표에는 비어 있었고, 이 한 줄이
없으면 모든 성능 비교가 의미를 잃는다.

### 1.1 학습 모델이 값어치를 낼 수 있는 자리는 두 블록뿐이다

| 블록 | scDFM이 ridge보다 | 조건 |
|---|---|---|
| Table 2 Double | **+0.220** | 조합, 단일이 홀드아웃 |
| Table 3 | **+0.201** | 조합, 단일이 홀드아웃 |
| Table 1 Double | −0.035 | 조합, 모든 단일이 학습에 있음 |
| Table 2 Single | **−0.203** | 홀드아웃 단일 |

**홀드아웃된 단일에서는 학습 모델이 닫힌 형태 회귀에 진다.** scDFM 1.619, scPKFM 1.754,
ridge 1.416. 특정 모델의 결함이 아니라 공통 현상이므로, 벤치마크의 성질로 보고해야 한다.

## 2. 과제를 다시 쓰는 항등식

신호의 **88%가 가법적**이다. 그리고 조합 `S`에 대해 ridge가 남긴 잔차를
`r_S = m_참값 − m_control − Σ w_a` 라 하면

```
L2(ridge) = ||r_S||        — 항등식
```

ridge의 예측이 `m_control + Σ w_a`이므로 **그 오차가 곧 잔차 자체**다. 따라서
"베이스라인보다 얼마나 잘하는가"는 **"잔차를 얼마나 정확히 예측하는가"**와 같은 질문이다.
이 등식이 평가 설계 전체를 결정한다.

---

## 3. 벤치마크가 얼마나 도달 가능한지 — ρ와 천장

예측 잔차와 참 잔차의 코사인을 `ρ`, 노름 비를 `k`라 하면 남는 오차는

```
||r|| sqrt(1 − 2kρ + k²)       k = ρ에서 최소,  값은 ||r|| sqrt(1 − ρ²)
```

`||r||`이 곧 ridge의 L2이므로, **`ρ` 하나가 그 모델이 도달할 수 있는 최대 상대 개선을
고정한다.** 어떤 보정을 붙여도 넘지 못한다.

측정된 천장 (조건별 최적 스케일을 오라클로 주었을 때):

| 검증 family | ρ | 천장 | 요구치 | 달성 |
|---|---|---|---|---|
| combosciplex:sv (Table 3) | 0.582 | −18.69 % | −10.83 % | −14.21 % |
| norman:ncomb (Table 2 Double) | 0.500 | −13.40 % | −9.77 % | −7.09 % |
| norman:nval (Table 1) | 0.526 | −14.96 % | 불필요 | −6.99 % |

**Table 2 Double은 천장이 −13.40%인데 요구치가 −9.77%다.** 오라클의 73%를 잡아야
통과한다. 이 방법 부류에게 그 블록은 거의 포화되어 있다는 뜻이고, 이것은 모델이 아니라
**벤치마크에 대한 진술**이다.

## 4. 잡음이 보고되는 효과보다 크다

| 측정 | 값 |
|---|---|
| combosciplex seed SD (조건 내, pooled) | 0.0287 ~ 0.046 |
| norman:ncomb seed SD | 0.0042 |
| scPKFM(v1) combosciplex seed SD | 0.28 |
| 최적 전역 스케일의 fold 간 전이 손실 | in-sample −0.0849 → 홀드아웃 −0.0472 |

**v1의 0.28은 그 프로젝트가 3주간 검출하려 한 모든 효과보다 컸다.** 단일 seed·단일 fold
수치는 서로 구분되지 않을 수 있다는 것이 이 벤치마크에 대한 진술이다.

마지막 줄도 중요하다: **같은 데이터셋의 fold 사이에서도 최적 하이퍼파라미터가 전이되지
않는다.** in-sample 수치는 체계적으로 낙관적이다.

## 5. 고정 사전은 무상관화해야 한다 — 가장 일반적인 결과

KEGG 경로들은 유전자를 공유하므로 관측 좌표가 강하게 상관된다. 저계수 연산자가 그 중복을
푸는 데 용량을 쓴다. **ZCA 백색화는 생성역을 건드리지 않고 기저만 바꾼다**(행공간 보존을
수치로 확인).

combosciplex:sv, fold 홀드아웃, 보정 후 L2 (바닥 = ridge 1.6773):

| 관측값 | 백색화 없음 | 백색화 |
|---|---|---|
| KEGG | 1.4953 | **1.4382** |
| PCA | 1.4560 | 1.4372 |

- **백색화가 KEGG에 −0.0571, PCA에 −0.0188로 3배를 준다.** 분산 평준화 효과였다면
  둘에 비슷했어야 한다. 조건수가 나빴던 쪽은 KEGG다.
- **백색화 후 두 사전이 0.0010 차이로 같아진다.**
- 사전 등록한 규칙이 **세 family 전부에서 백색화를 채택**했다 (combosciplex −0.0873,
  norman:ncomb −0.0238 ± 0.0109, norman:nval −0.0116 ± 0.0023). 이 프로젝트에서 유일하게
  **복제된** 구조적 개선이다.

eDMD의 사전 선택 문제에 대한 진술로 읽힌다: **데이터 밖에서 온 고정 사전이 학습된 사전과
동등하다 — 단, 중복을 제거한 뒤에.**

## 6. 실패한 것 — 생물학적 사전지식이 하중을 받지 않았다

사전 등록한 세 주장 중 둘이 명시된 형태로 반증되었다.

**주장 A — "KEGG가 원칙적 Koopman 관측 사전이다. 특히 PCA보다 나아야 한다."**
반증. 백색화 전에는 PCA가 이기고 KEGG는 **같은 폭의 무작위 사전과 구분되지 않는다**
(−0.0173 ± 0.0136 대 −0.0155 ± 0.0188). 백색화 후에는 PCA와 비긴다. 어느 쪽에서도
"생물학이 더 낫다"는 성립하지 않는다.

**주장 B — "비가법성은 경로 매개다."** 철회. dense readout이 더 좋다. 설계서가 미리
"좋으면 철회"라고 적어 두었고 그대로 따랐다.

**주장 C — "동시 섭동 합성의 올바른 대칭은 반교환자다."** 약하게 유지. s=1에서
이선형 +0.0098 ± 0.0160, 단순합 +0.0134 ± 0.0317로 둘 다 반교환자보다 나쁘지만,
보정 후에는 단순합이 반교환자와 비긴다 (1.5290 대 1.5301).

### 6.1 이 결론의 한계 — 시험한 영역이 좁다

생물학적 사전지식은 **학습 조건을 전부 주고, 한 데이터셋 안에서, 평균 L2 하나로**만
비교되었다. 그것은 사전지식이 가장 도움이 되지 않는 조건이다. 시험하지 않은 영역:

- **저데이터** — 조건 수를 줄이면 고정 사전이 유리해지는가. 손잡이는 구현되어 있다
  (`split.train_condition_fraction`).
- **데이터셋 간 전이** — Norman에서 맞춘 연산자 기저를 combosciplex로 옮기는 것은
  **고정 사전에서만 가능**하다. PCA 축은 데이터셋이 바뀌면 의미가 없다.
- **해석 가능성** — KEGG 좌표에서 `A_a`는 경로 × 경로 연산자이고 주요 모드를 읽을 수
  있다. 알려진 약리학과 대조 가능하다. PCA 좌표에는 이 그림이 존재하지 않는다.

**세 영역 모두 미측정이다.** 위의 반증은 "시험한 영역에서 하중을 받지 않았다"이지
"어떤 영역에서도 받지 않는다"가 아니다.

## 7. 측정하지 않은 것

- **Flow Matching과 OT 결합의 기여.** FM 손실을 끄고 endpoint 손실만으로 학습한
  대조군을 한 번도 돌리지 않았다. 두 부품이 실제로 무엇을 하는지 모른다.
- **w12** — 무작위 사전 + 백색화, 상위분산 유전자 + 백색화. 주장 A의 마지막 조각.
- `composition=commutator`, `readout=random` — ablation 표의 대조군.
- 보고용 테스트 집합. **의도적으로 한 번도 채점하지 않았다.**

## 8. 재사용 가능한 도구

모델과 무관하게 섭동 예측 프로젝트에 그대로 쓸 수 있다.

| | 역할 |
|---|---|
| `scripts/baseline_l2.py` | 보고된 지표로 베이스라인 L2. 어떤 표에든 ridge 행을 넣는다 |
| `scripts/dev_queue.py` | GPU당 하나의 순차 큐. 팔은 config 덮어쓰기, 중단 후 재개 가능 |
| `scripts/dev_score.py` | 사전 등록 규칙, seed 잡음, ρ와 천장 |
| `scripts/dev_shrink.py` | `L2(s) = sqrt(ee + 2s·er + s²rr)` — 학습 없이 임의의 스케일 규칙을 정확히 평가 |
| `scripts/dev_reliability.py` | 조건별 신뢰도 예측자의 AUC |
| `scripts/dev_rule.py` | 규칙 족의 교차검증 비교. **노이즈 컬럼이 이기지 못하는지 테스트로 고정** |
| `scripts/dev_status.py` | 큐 진척 |
| `scripts/md_to_pdf.py` | 한글 문서 → PDF (폰트에 없는 글자를 조용히 버리지 않음) |

규율 자체도 가져갈 가치가 있다: **사전 등록한 채택 규칙, 보정은 학습 fold에서 적합해
홀드아웃 fold에서 채점, 테스트는 한 번도 보지 않음.** v1은 선택하면서 테스트를 열세 번
채점했고 그래서 어떤 결과도 읽을 수 없게 되었다.

## 9. 이 저장소에서 쓸 수 있는 논문

아키텍쳐 논문은 아니다. **벤치마킹 논문**은 숫자가 이미 전부 측정되어 있다.

> 이 분야의 발표된 모델들이 닫힌 형태 가법 적합에 네 표 중 둘에서 진다. 왜 그런지 보이고
> (§1.1, §2), 각 블록이 애초에 얼마나 도달 가능한지 측정하고 (§3), 보고되는 효과보다
> 잡음이 크다는 것을 보이고 (§4), 구조적으로 그렇게 질 수 없는 모델을 제시한다 —
> 학습 전 예측이 베이스라인과 정확히 같고, 단일 교란의 예측은 학습이 끝날 때까지
> 베이스라인과 정확히 같다.

목표였던 "생물학적 사전지식이 하중을 받는 아키텍쳐"는 아니다. 기록으로 남긴다.

## N. ComboSciPlex의 실현 격차는 조절 가능한 것이 아니다

`scPKR`의 예측 평균(soft)과 그 평균에서 실현한 세포들의 평균(sample)은 블록마다 이만큼
벌어진다.

| 블록 | 차이 |
|---|---|
| Table 2 Single | +0.047 |
| Table 2 Double | +0.070 |
| Table 1 | +0.091 |
| **Table 3 ComboSciPlex** | **+0.697** |

ComboSciPlex만 7~10배다. 손잡이를 전부 돌려 보았고 **어느 것도 움직이지 않았다.**

| 바꾼 것 | combosciplex 차이 | norman_add 차이 |
|---|---|---|
| 보정 계수 1.77 → 1.00 | +0.676 → +0.686 | +0.086 → +0.087 |
| `q_floor` 0.01 → 0.50 | +0.668 → +0.773 | +0.084 → **+0.021** |
| 캡 제거 | L2 **465.66** | — |

`q_floor`는 norman에서 작동한다 — 0.084에서 0.021로 내려간다. combosciplex에서는 **오히려
나빠진다.** 같은 기전이 아니라는 뜻이다.

### 원인: 음수 예측

세포 하나하나를 보면 **ComboSciPlex 예측의 33.8%가 음수**다 (norman은 23.5%). 발현량은
음수가 될 수 없으므로 양수만 내놓는 어떤 실현도 이것을 재현할 수 없다.

**어떤 실현이든 도달 가능한 최선**을 직접 계산하면 — 음수를 0으로 누른 뒤 조건 평균을 내면:

| | soft | 음수를 0으로 | 비용 | 실제 실현(sample) |
|---|---|---|---|---|
| combosciplex | 1.6220 | 2.4226 | **+0.8006** | 2.2648 |
| norman_add | 1.5173 | 1.5285 | +0.0110 | 1.5322 |

**비음수성을 요구하는 것만으로 ComboSciPlex에서 0.80을 잃는다.** norman에서는 0.011이다.

그리고 실제 실현은 2.2648로 **그 단순한 하한 2.4226보다 이미 낫다.** 실현 경로는 할 수 있는
것을 다 하고 있고, 그래서 어느 손잡이에도 반응하지 않았다.

### 결론

이 격차는 실현의 결함이 아니라 **예측의 성질**이다. 고치려면 출력을 비음수로 다시
파라미터화하고 33개 run을 재학습해야 하며, 실현 경로에서 할 수 있는 일은 없다.

보고할 때 L2는 모델이 내놓는 평균(soft)으로 하고 — 집단 평균 사이의 L2가 묻는 것이 바로
그 값이다 — **이 모델이 ComboSciPlex에서 세포 생성기가 아니라는 사실을 명시한다.** 숨기면
리뷰어가 가장 먼저 찾을 자리다.
