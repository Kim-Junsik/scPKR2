# 모델 수식 읽는 법

이 문서는 **이 분야를 처음 접하는 사람**을 위한 것이다. 사전 지식을 가정하지 않고 수식의
기호를 하나씩 설명한다. 모델의 설계 근거는 [MODEL.md](MODEL.md), 측정 결과는
[FINDINGS.md](FINDINGS.md)에 있다.

전체 수식은 이것이다.

```
Dx(S, x) = Sum_{a in S} w_a                                  (1) 가법, 닫힌 형태
         + 1[|S| >= 2] . s . W (exp(B_S) - I) Phi(x + Sum w_a)   (2) 학습된 항

x_pred   = head( x + Dx(S, x) )                              (3) 세포 집단으로 실현
```

기호가 일곱 개뿐이다. 하나씩 본다.

---

## 0. 데이터가 무엇인가

세포 하나를 측정하면 **유전자 5,000개가 각각 얼마나 발현되었는지**를 나타내는 숫자
5,000개가 나온다. 그것이 벡터 하나다.

```
x = [ 0.0,  2.3,  0.0,  1.1,  0.0,  0.0,  4.7,  ... ]      숫자 5,000개 = 세포 한 개
       ^     ^                         ^
    유전자1 유전자2                  유전자7
```

**0이 아주 많다.** 단일세포 데이터에서 유전자 하나가 세포의 5 %에서만 검출되는 일이 흔하다.
이 사실이 (3)에서 중요해진다.

약물을 처리하거나 유전자를 과발현시키면 세포들이 다른 상태로 옮겨간다. **어디로 가는지
예측하는 것**이 과제다.

| 기호 | 뜻 | 크기 |
|---|---|---|
| `x` | 처리하지 않은 세포 하나 (출발점) | 숫자 5,000개 |
| `S` | 가할 교란의 집합, 예: {Panobinostat, Dasatinib} | 보통 1개 또는 2개 |
| `S`의 크기 | S에 들어 있는 교란의 개수 | 1 또는 2 |
| `Dx(S, x)` | **얼마나 움직일 것인가** — 수식 전체가 이것을 계산한다 | 숫자 5,000개 |

---

## 1. `Sum_{a in S} w_a` — 가법 부분

### `w_a` : "교란 a 하나가 평균적으로 하는 일"

숫자 5,000개짜리 벡터. 양수면 그 유전자를 올리고, 음수면 내린다.

```
w_Panobinostat = [ +0.8,  -0.2,   0.0,  +1.4,  ... ]
w_Dasatinib    = [ -0.1,  +0.5,   0.0,  -0.3,  ... ]
```

### `Sum_{a in S}` : 그냥 더한다

`Sum`은 합, `a in S`는 "S에 든 각 교란 a에 대해"라는 뜻이다. 둘을 가하면 두 벡터를 더한다.

**이 항이 말하는 것: "두 약물을 같이 쓰면 각각이 하는 일의 합이 일어난다."**
현실에서 **88 % 맞는다.** 그래서 이 항이 예측의 대부분을 담당한다.

### 어떻게 구하나 : "닫힌 형태"

**ridge 회귀** 한 번이다. 알고 있는 조건을 늘어놓고 연립방정식을 푼다.

```
조건                 관측된 변화
약물A 단독      =    w_A
약물B 단독      =    w_B
약물A + 약물B   =    w_A + w_B
약물A + 약물C   =    w_A + w_C
...
```

이 식들을 가장 잘 만족하는 `w` 들을 **공식 하나로** 구한다. 반복 학습도 없고 무작위성도
없다. 그래서 **닫힌 형태(closed form)**라 부른다. 같은 데이터면 언제나 같은 답이 나온다.

쓸모 있는 성질이 하나 있다. `w_A`는 **A가 등장한 모든 조건**에서 함께 추정되므로,
**A를 단독으로 한 번도 써 보지 않았어도** 조합들로부터 `w_A`가 나온다.

## 2. `W (exp(B_S) - I) Phi(x + Sum w_a)` — 학습된 보정

(1)이 88 %를 맞추므로 (2)는 **남은 12 %**, 즉 "같이 쓰면 달라지는 부분"만 담당한다.
안쪽에서 바깥으로 읽는다.

### `x + Sum w_a` : 먼저 가법 추측만큼 옮긴 지점

보정은 원래 세포가 아니라 **일단 더해서 옮겨 놓은 지점**에서 계산한다.

### `Phi` : 유전자 언어를 **경로 언어**로 옮기는 번역기

`418 x 5000` 크기의 **고정된** 행렬. 학습하지 않는다.

```
Phi( 유전자 5,000개 )  ->  경로 418개
```

418개의 구성:

- **162개** KEGG 데이터베이스의 생물학적 경로. 각 숫자는 **그 경로에 속한 유전자들의 평균
  발현**이다. 예를 들어 "세포주기 경로가 얼마나 활성화되어 있는가"가 숫자 하나가 된다.
- **256개** 개별 유전자를 그대로 읽는 좌표. **교란당한 유전자 자신이 보여야** 하는데,
  Norman 데이터의 타겟 101개 중 53개가 KEGG의 어떤 경로에도 들어 있지 않다.

**왜 경로로 바꾸는가.** 두 가지 이유가 있다.

생물학적으로는 작용이 경로 단위로 일어난다. 수학적으로는 — 이것이 **Koopman 이론**인데 —
**유전자 공간에서 복잡하게 휘어 있는 동역학이 좌표를 잘 고르면 선형이 된다.** 그 "잘 고른
좌표"를 관측량(observable)이라 하고, 무엇을 고를 것인가가 이 이론의 중심 난제다. 이 모델은
**KEGG로 답했다.**

### `A_a` : 교란 a의 "밀어내기 규칙"

`418 x 418` 행렬. **벡터가 아니라 행렬이라는 점이 핵심이다.**

| | 뜻 |
|---|---|
| 벡터라면 | "경로 3을 0.5만큼 올려라" — 상태와 무관한 고정된 밀기 |
| **행렬이면** | **"경로 3이 높으면 경로 7을 올려라"** — 현재 상태에 따라 달라지는 규칙 |

생물학이 그렇다. 약물의 효과는 세포가 지금 어떤 상태인지에 달려 있다.

### `B_S` : 두 교란의 규칙을 **합성**

```
B_S = Sum_{a<b}  ( A_a A_b  +  A_b A_a )
```

`A_a A_b`는 행렬 곱이다.

**왜 곱하는가.** 상호작용이란 **A의 밀기가 B의 밀기를 바꾸는 것**이고, 그것이 수학적으로
곱이다.

**왜 두 순서를 더하는가.** 동시에 가하는 실험에는 **순서가 없다.** A 다음 B나 B 다음 A나
같은 실험이다. `A_a A_b + A_b A_a`는 두 교란을 바꿔 넣어도 값이 같다. 이것을
**반교환자(anticommutator)**라 한다. 반대로 `A_a A_b - A_b A_a`(교환자)는 바꿔 넣으면
부호가 뒤집히므로, 순서가 없는 실험에는 담을 내용이 없다.

**그리고 이 형태는 고른 것이 아니라 유도된다.**

```
실제 동시 섭동       exp(t(A+B))
가법적 예측          exp(tA) + exp(tB) - I

   차이  =  exp(t(A+B)) - [ exp(tA) + exp(tB) - I ]
         =  (t^2/2)(A+B)^2 - (t^2/2)(A^2 + B^2) + O(t^3)
         =  (t^2/2)( AB + BA ) + O(t^3)
```

**비가법성의 가장 큰 항이 정확히 반교환자다.** 유추가 아니라 항등식이다.

### `exp(B_S)` : 비율을 **결과**로 바꾼다

`B_S`는 **변화의 속도**다. 실제 변화는 그 속도로 한 단위 시간을 흐른 결과이고, 그것이
**행렬 지수**다.

이자율로 비유하면, 연이율 `r`로 연속 복리를 할 때 1년 뒤 금액은 `1 + r`배가 아니라 `e^r`
배다. **속도를 결과로 바꾸는 것이 지수함수다.** 여기서는 숫자가 아니라 행렬이므로
`exp(B_S)`가 된다. 근사가 아니라 미분방정식 `dp/dt = B_S p`의 **정확한 해**다.

### `- I` : "아무것도 하지 않은 경우"를 뺀다

`I`는 항등행렬, 즉 "그대로 두기"다. `exp(B_S)`는 **도착점**이므로 거기서 출발점을 빼면
**변화량**만 남는다.

### `W` : 경로 언어를 유전자 언어로 **되번역**

`5000 x 418` 행렬. (2)가 내놓아야 하는 것은 유전자 5,000개에 대한 보정이므로 되돌려야 한다.

**`W`는 0에서 시작한다.** 그래서 학습 전에는 (2) 전체가 0이고 모델이 정확히 ridge다.
아래 정리 1이 여기서 나온다.

### `s` : "이 조건에서 이 보정을 얼마나 믿을까" 다이얼

0에서 4 사이의 숫자 하나.

| `s` | 뜻 |
|---|---|
| 0 | 보정을 쓰지 않는다 (= ridge 그 자체) |
| 1 | 모델이 낸 그대로 쓴다 |
| 2 | 두 배로 쓴다 |

필요한 이유는 측정에서 나왔다. 모델이 내는 보정의 **방향은 꽤 맞는데 크기가 조건마다
어긋난다.** 그래서 조건별로 크기를 조절한다. **학습이 아니라 검증 데이터에서 사후에**
맞추며, 학습 fold에서 적합해 홀드아웃 fold에서 채점한다.

### `1[|S| >= 2]` : 스위치

대괄호 안이 참이면 1, 거짓이면 0이다. **교란이 2개 이상일 때만 (2)를 켠다.**

사실 이것은 설명을 위한 표기다. `B_S`가 **쌍**에 대한 합이므로 교란이 하나면 쌍 자체가
없어서 자동으로 0이 된다.

## 3. `head(...)` — 숫자를 **세포 집단**으로

(1)과 (2)가 주는 것은 **평균이 어디로 가는가**이다. 그런데 예측해야 하는 것은
**세포들의 분포**이고, 앞서 보았듯 **데이터에 0이 아주 많다.**

그래서 유전자마다 두 조각으로 모델링한다. 문턱을 넘느냐 마느냐를 먼저 보므로
**hurdle**(문턱)이라 부른다.

```
1) 이 유전자가 아예 검출되는가 ?      확률  q = sigmoid( a . mu + b )
2) 검출된다면 얼마나 ?                크기  mu / q
```

`sigmoid`는 어떤 숫자든 0과 1 사이로 눌러 주는 함수여서 확률이 된다.

**핵심은 두 조각을 곱하면 원래 평균으로 돌아온다는 것이다.**

```
q  x  ( mu / q )  =  mu
```

평균 1.0을 원하는데 세포의 20 %에서만 검출된다면, 그 20 %에 5.0씩 주면 전체 평균이 1.0이
된다. 이 성질을 **평균 보존**이라 하고, 이것이 없으면 아래 정리 1이 깨진다.

## 4. 이 수식에서 공짜로 따라오는 것 두 개

둘 다 튜닝된 행동이 아니라 **움직일 파라미터가 없어서** 성립한다.

### 정리 1 — 학습 전 모델은 ridge와 정확히 같다

`W = 0`이므로 (2)가 항등적으로 0이고, head는 평균을 움직이지 못한다. 따라서 학습 시작점의
예측은 `m_control + Sum w_a`, 즉 ridge 그 자체다. 실측값 1.857668 대 1.857669.

**모델이 검증된 출발점에서 시작하고 아래로만 갈 수 있다는 뜻이다.**

### 정리 2 — 교란이 하나면 영원히 ridge와 같다

`B_S`는 **쌍**에 대한 합이다. 크기 1인 집합에는 쌍이 없으므로 항이 존재하지 않는다.
학습이 침식할 수 있는 성질이 아니다.

**이것이 중요한 이유.** 홀드아웃된 단일 교란은 **발표된 학습 모델들이 모두 닫힌 형태 회귀에
지는 자리**다. Norman 데이터에서 ridge가 1.416, 발표된 모델들이 1.619와 1.754다. 이 모델은
**거기서 질 수가 없다.**

## 5. 무엇이 학습되고 무엇이 아닌가

| 기호 | 정체 | 크기 | 학습? |
|---|---|---|---|
| `w_a` | 교란별 효과 벡터, ridge 적합 | 17 x 5,000 | **아니오** (닫힌 형태) |
| `Phi` | 관측 사상, KEGG 162 + anchor 256 | 418 x 5,000 | **아니오** (고정) |
| `A_a` | 교란별 밀어내기 규칙 | 418 x 418, 교란마다 | 예 (84,144개) |
| `W` | 경로에서 유전자로 되번역 | 5,000 x 418 | 예 (2,090,000개) |
| `head` | 영 과잉 분포의 두 조각 | — | 예 (15,000개) |
| `s` | 조건별 신뢰 다이얼 | 스칼라 | **아니오** (검증에서 적합) |

학습 파라미터는 모두 **2,189,144개**이고 그중 95 %가 `W` 하나다. `W`의 크기는 용량을
고른 결과가 아니라 **유전자 수가 정하는 값**이다. 실제로 상호작용을 담당하는 `A_a`는
84,144개다.

## 6. 한 줄 요약

> **신호의 88 %는 그냥 더하면 맞으므로 공식으로 고정하고 (1), 남은 12 %의 "같이 쓰면
> 달라지는 부분"만 배운다 (2). 그 학습은 유전자가 아니라 경로 좌표에서 하고, 두 교란의
> 상호작용은 각자의 밀어내기 규칙을 곱해 합성하며, 결과는 세포 집단으로 실현한다 (3).**
