# scPKR — 경로 Koopman 잔차 모델

이 문서는 모델을 처음 보는 사람을 대상으로 한다. 사전 지식을 가정하지 않고, 생물학적
근거와 수학적 구조를 각 조각에서 함께 설명한다. 설계 과정과 폐기된 시도는
[DESIGN.md](DESIGN.md)에 있다.

---

## 1. 무엇을 예측하는가

단일세포 전사체 데이터에서, **어떤 교란(유전자 과발현 또는 약물)을 가했을 때 세포가
어떤 상태로 옮겨가는지**를 예측한다.

- **입력**: 처리하지 않은 세포(control)의 발현 벡터 `x ∈ R^G`, 그리고 가할 교란의 집합
  `S` (예: `{Panobinostat, Dasatinib}`)
- **출력**: 그 교란을 받은 세포 집단의 발현 분포
- **평가**: 예측 집단의 평균과 실제 집단의 평균 사이 L2 거리

핵심 난점은 **조합**이다. 단일 교란 A와 B를 각각 본 적이 있어도, A와 B를 동시에 가한
결과는 두 효과의 합이 아니다. 두 교란이 같은 경로를 건드리면 서로를 증폭하거나
상쇄한다. 그리고 실험으로 가능한 조합의 수는 교란 수의 제곱으로 늘어나므로, **본 적 없는
조합을 예측하는 것**이 이 문제의 전부다.

두 벤치마크를 쓴다.

| | 교란 종류 | 교란 수 | 유전자 | 세포 |
|---|---|---|---|---|
| Norman | CRISPRa 유전자 과발현 | 101 | 5,000 | 85,000 |
| ComboSciPlex | 약물 | 17 | 5,000 | 63,000 |

## 2. 출발점이 되는 관찰 두 개

### 2.1 신호의 88%는 가법적이다

교란 A의 효과 벡터를 `w_A = m_A − m_control` 이라 하면, 조합 `A+B`의 실제 변화는
대부분 `w_A + w_B`로 설명된다. 비가법 부분은 12%에 불과하다.

그래서 **가법 부분을 학습할 이유가 없다.** 닫힌 형태로 풀면 된다. 학습 조건들에 대해
원-핫 ridge 회귀 하나를 푼다.

```
X : 조건 수 × 교란 수     조건 A+B의 행은 A열과 B열이 1
Y : 조건 수 × 유전자 수   각 행이 m_조건 − m_control
풀이 : (X^TX + αI) W = X^TY          →  교란별 효과 벡터 w_a
예측 : m_pred(S) = m_control + Σ_{a∈S} w_a
```

이것을 `ridge_additive`라 부른다. 상호작용 항도, 신경망도 없다. 결정론적이라 seed
잡음이 0이다. 그런데도 **네 개의 보고 표 중 둘에서 발표된 딥러닝 모델들을 이긴다.**

여기에 쓸모 있는 성질이 하나 있다: `w_a`는 그 교란이 등장한 **모든** 조건(단일이든
조합이든)에서 pooling된다. 따라서 **학습에 단일이 한 번도 없는 약물도 `w_a`를 갖는다.**

### 2.2 남은 12%가 정확히 모델이 할 일이다

조합 `S`에 대해 ridge가 남긴 잔차를

```
r_S = m_참값 − m_control − Σ_{a∈S} w_a
```

라 하자. ridge의 예측이 `m_control + Σ w_a`이므로

```
L2(ridge) = ||r_S||        — 항등식
```

**ridge의 오차가 곧 잔차 그 자체다.** 그러므로 "ridge보다 얼마나 잘하는가"라는 질문은
**"잔차 `r_S`를 얼마나 정확히 예측하는가"**와 같은 질문이다. 이 등식이 모델의 설계와
평가 전체를 결정한다.

## 3. 모델

```
Δx(S, x) = Σ_{a∈S} w_a                                      ① 가법, 닫힌 형태
         + 1[|S| ≥ 2] · s · W (exp(B_S) − I) Φ(x + Σ_{a∈S} w_a)   ② 상호작용, 학습됨

x_pred = x + Δx(S, x)                                            ③ hurdle head로 실현
```

읽는 법: **control 세포를 먼저 가법 성분만큼 옮기고(①), 그 지점에서 경로 좌표로 올라가
Koopman flow를 흘린 뒤 유전자 공간으로 되읽어 보정한다(②).** 단일 교란이면 ②는 아예
존재하지 않는다.

```
   x  ──①──►  x + Σw_a  ──Φ──►  p ∈ R^K  ──exp(B_S)──►  p'  ──W──►  보정  ──②──►  x_pred
 유전자 공간              경로(관측) 공간, 선형 flow          유전자 공간
```

## 4. 각 조각

### ① 가법 성분 `w_a` — 학습되지 않는다

§2.1의 ridge 적합이 그대로 들어온다. 모델 안에서 **버퍼**로 저장된다. 즉 체크포인트에
담겨 다니지만 경사를 받지 않는다.

**왜 학습하지 않는가.** 결정론적이므로 seed 잡음을 만들지 않고, 88%를 이미 설명하며,
학습된 항과 같은 것을 설명하려 경쟁하면 식별성이 무너진다. 이전 버전에서 학습 가능한
두 항이 같은 변위를 설명할 수 있게 두었더니 서로를 상쇄하며 어느 쪽도 의미 있는 값을
갖지 않았다.

### `Φ` — 경로 관측 사전 (생물학이 들어오는 자리)

`Φ`는 유전자 공간 `R^G`에서 **관측 공간** `R^K`로 가는 **고정된 선형 사상**이다.
학습 파라미터가 없다.

```
Φ(x) = ZCA · ( (x · M^T − μ) / σ )
```

`M`은 `K × G` 행렬이고 두 블록으로 이루어진다.

- **경로 블록** — KEGG 데이터베이스의 각 경로 하나당 좌표 하나. 그 경로에 속한 유전자들의
  평균 발현. ComboSciPlex에서 162개 경로가 살아남는다(크기 10–300으로 거른 뒤).
- **anchor 블록** — 유전자를 직접 읽는 좌표. 256개.

**anchor 블록이 왜 필요한가.** 교란된 유전자 자신이 관측 가능해야 한다. Norman의 101개
타겟 중 **53개가 KEGG의 어떤 경로에도 들어 있지 않다** — HOX/FOX/DLX/LHX 같은 발생
전사인자 묶음을 KEGG가 다루지 않기 때문이다. 교란된 유전자를 볼 수 없는 관측 공간은
그 효과를 표현할 수 없다. ComboSciPlex는 약물이라 타겟 유전자가 데이터에 아예 없고,
거기서는 분산이 가장 큰 유전자들이 anchor가 된다.

**왜 고정하는가 — Koopman의 핵심.** Koopman 이론은 비선형 동역학을 **관측량(observable)의
공간에서는 선형**으로 볼 수 있다고 말한다. 문제는 *어떤 관측량을 쓸 것인가*이고, 이것이
eDMD(extended Dynamic Mode Decomposition)의 중심 난제다. 통상적인 답은 다항식, RBF,
또는 학습된 인코더다. **KEGG는 생물학적인 답이다**: 데이터 밖에서 왔으므로 데이터에
과적합될 수 없고, 고정되어 있으므로 재구성 손실이 없고 따라서 오토인코더 병목도 없다.

**`ZCA`는 왜 있는가.** 경로들은 유전자를 공유한다 — 같은 유전자가 여러 경로에 들어간다.
그래서 좌표들이 강하게 상관되어 있고, 저계수 연산자가 그 중복을 푸는 데 용량을 쓴다.
ZCA 백색화(공분산의 대칭 역제곱근)는 **생성역은 그대로 둔 채 기저만 무상관으로** 바꾼다.
`M`의 행공간이 바뀌지 않는다는 것은 수치로 검증되어 있다.

**표준화와 백색화는 학습 세포에서만 적합**되고 한 번 정한 뒤 다시 맞추지 않는다. 홀드아웃
조건의 세포는 여기에도, 유전자 선택에도, 분할에도 닿지 않는다.

### `A_a` — 교란별 Koopman 생성자

교란 `a` 하나당 `K × K` 행렬 하나. 저계수로 매개한다.

```
A_a = U diag(c_a) V  +  P_a Q_a
      └─ 공유, rank 32 ─┘  └ 개별, rank 4 ┘
```

**공유 부분**은 모든 교란이 같은 기저 `U, V`를 쓰고 계수 `c_a`만 다르다. 교란들이
공통으로 보이는 반응(스트레스 응답, 세포주기 정지 같은)을 여기서 먼저 배우고, 개별
부분이 거기서 분기한다. `c_a`는 전부 1에서 시작한다 — 모든 교란이 모든 공유 모드를
동등하게 쓰는 상태에서 출발한다.

생성자(generator)라고 부르는 이유는 이것이 **시간당 변화율**이고, 실제 변위는 그 지수로
얻기 때문이다(아래 `exp`).

### `B_S` — 합성 법칙 (수학이 들어오는 자리)

여러 교란을 동시에 가했을 때의 생성자를 **무순서 쌍에 대한 반교환자(anticommutator)의
합**으로 둔다.

```
B_S = Σ_{a<b, a,b ∈ S} ( A_a A_b + A_b A_a )
```

**왜 반교환자인가.** 가법적 예측이란 관측 공간에서 "각 교란의 flow를 따로 적용하고
겹친 것", 즉 `exp(tA) + exp(tB) − I` 이다. 실제 동시 섭동은 `exp(t(A+B))` 이다. 둘의
차이를 전개하면

```
exp(t(A+B)) − [ exp(tA) + exp(tB) − I ]
    = t²/2 · (A+B)² − t²/2 · (A² + B²) + O(t³)
    = t²/2 · (AB + BA) + O(t³)
```

**비가법성의 선두항이 정확히 반교환자다.** 이것은 유추가 아니라 항등식이다.

그리고 대칭이 맞는다. 동시 이중 섭동은 **교환 대칭**을 갖는다 — A와 B를 동시에 가하는
것과 B와 A를 동시에 가하는 것은 같은 실험이다. `AB + BA`는 대칭이므로 그 성질을 갖는다.
반대로 교환자 `AB − BA`는 **반대칭**이어서 순서 의존성을 표현하는데, 동시 섭동에는
순서가 없으므로 담을 신호가 없다. (이전 버전에서 교환자를 썼고 5전 5패였다.)

**어떤 파라미터도 교란의 쌍으로 색인되지 않는다.** `A_a`는 교란 하나당 하나이고, 쌍은
곱으로만 생긴다. 이것이 **본 적 없는 조합을 표현 가능하게 만드는 구조적 이유**다 — 본
적 있는 쌍만이 맞출 수 있었던 파라미터가 존재하지 않는다.

### `exp(B_S) − I` — flow map

`B_S`는 생성자이고, 실제 변위는 자율 선형장 `dp/dt = B_S p`를 단위 시간 흘린 결과다.

```
p(1) = exp(B_S) p(0)        exp는 행렬 지수
```

그래서 변위는 `(exp(B_S) − I) p(0)`. 오일러 근사가 아니라 **정확한 해**를 쓴다.

여기가 Koopman 전제가 실현되는 자리다: **유전자 공간에서는 비선형인 동역학이, 올바른
관측 좌표에서는 선형 연산자 하나로 기술된다.** 비선형성은 `B_S`가 `A_a`들의 곱이라는
점과 행렬 지수에 들어 있고, 상태 `p`에 대해서는 선형이다.

### `W` — readout

관측 공간의 변위를 유전자 공간으로 되읽는 `G × K` 선형 사상.

**0에서 시작한다.** 이것이 모델의 두 정리 중 첫 번째를 만든다(§5).

### hurdle head — 집단의 실현

예측은 평균 벡터가 아니라 **세포 집단**이어야 한다. 단일세포 데이터는 영이 많다 — 유전자
하나가 세포의 5%에서만 검출되는 일이 흔하다. 그래서 각 유전자를 두 조각으로 모델링한다.

```
검출 확률  q_g = σ(a_g · μ_g + b_g)
검출됐을 때의 크기  μ_g / q_g
```

**평균 보존**이 핵심이다: `q · (μ/q) = μ`. 즉 head는 집단의 평균을 움직이지 않고
분포 모양만 만든다. 이 성질이 없으면 §5의 정리가 깨진다.

### `s` — 조건별 보정

잔차의 **방향**은 신뢰할 수 있지만 **크기**는 그렇지 않다. 조건별로 최적 스케일은
`ρ||e||/||r||`인데(여기서 `ρ`는 예측 잔차와 참 잔차의 코사인), 측정하면 `ρ`가 조건마다
−0.51에서 +0.82까지 요동치는 반면 모델이 내는 크기는 그렇지 않다. 그래서 추론 시점에
한 조각의 보정을 붙인다.

```
s = clip( c · ||Σ_{a∈S} w_a||^q · ||r_mean||^(−p),  0,  4 )
```

`r_mean`은 그 조건의 평균 잔차다. `q`와 `p`는 **고르는 것이 아니라 재는 것**이다 — `q=0, p=0`이면
정확히 상수 배율이고, `q=p=1`이면 보정의 크기가 가법 변위에 비례한다. 데이터셋마다
검증 fold에서 적합하며, 실제로 서로 다른 값이 나온다(ComboSciPlex `q=0.00, p=0.8`,
Norman `q=0.75~1.50, p=0.7~1.0`).

`s = 0`이면 모델은 정확히 `ridge_additive`다. 즉 보정은 **베이스라인과 학습된 모델
사이를 보간**하며, 적합된 값이 "잔차 중 얼마가 일반화되는가"를 말해 준다.

## 5. 구조적으로 보장되는 성질 두 가지

둘 다 튜닝된 행동이 아니라 **움직일 파라미터가 없어서** 성립한다. 단위 테스트가 숫자로
확인하고, 모든 학습 실행이 시작 전에 실제 데이터에서 다시 확인한다.

### 정리 1 — 학습 전 모델은 ridge와 정확히 같다

`W = 0`이므로 ②가 항등적으로 0이고, head는 평균 보존이므로 평균을 움직일 수 없다.
따라서 학습 시작점의 예측은 `m_control + Σ w_a`, 즉 `ridge_additive` 그 자체다.
실측: 1.857668 대 1.857669.

**모델이 측정된 바닥에서 출발하고 아래로만 갈 수 있다.** 이전 버전은 2.138에서
출발했고 그중 0.97이 오토인코더 병목 — 수송을 시작하기 전에 이미 지불된, 제거 불가능한
오차였다.

### 정리 2 — 단일 교란의 예측은 영원히 ridge와 같다

`B_S`는 **쌍**에 대한 합이다. 크기 1인 집합에는 쌍이 없으므로 항이 존재하지 않는다.
학습이 침식할 수 있는 성질이 아니다.

**이것이 왜 중요한가.** 홀드아웃된 단일 교란은 **학습 모델들이 닫힌 형태 회귀에 지는
자리**다. Norman에서 ridge가 1.416, 발표된 모델들이 1.619와 1.754다. 특정 모델의
결함이 아니라 공통 현상이다. 이 모델은 **거기서 질 수가 없다.**

| flow matching | 관측 | 예측 속도장이 결합된 짝을 잇는 방향과 맞는가 |
| endpoint | 관측 | `exp(B_S)`로 흘린 종점이 목표 관측값과 맞는가 |
| gene endpoint | 유전자 | 예측 집단 평균이 실제와 맞는가 — **보고 지표 그 자체** |
| head likelihood | 유전자 | 영-과잉 분포의 적합도 |

**짝짓기는 미니배치 불균형 최적수송(unbalanced OT)으로 한다.** control 세포와 교란된
세포는 짝이 알려져 있지 않다 — 같은 세포를 처리 전후로 측정할 수 없기 때문이다. 그래서
어떤 control 세포가 어떤 교란 세포로 갔는지를 Sinkhorn으로 추정한다. **결합은 관측
공간에서** 계산한다. 5,000차원 유전자 공간보다 418차원 경로 공간에서 거리가 더 의미
있고, 가법 성분만큼 이미 옮긴 뒤라 수송 거리 자체가 짧아 추정이 잘 조건화된다.

학습은 **조합 조건에 대해서만** 이루어진다. 단일은 정리 2에 의해 이미 정확하므로 가르칠
것이 없다.

규모 (ComboSciPlex: `G=5,000`, `K=418`, `P=17`):

```
operators  (A_a)       84,144

head                   15,000
────────────────────────────
학습 합계           2,189,144

가법 버퍼 (학습 안 함)  85,000
```

PyTorch로 경사하강 학습하고, Flow Matching 목적함수와 OT 결합을 쓰며, 행렬 지수와

어텐션도, MLP 깊이도 없고, 관측 공간에서 상태는 선형 flow를 따른다. 그것이 Koopman의
전제이며, 깊게 만들지 않은 것은 측정에 근거한 결정이다(§5 정리 1의 각주 참조).

## 8. 한 문단 요약

**신호의 88%는 가법적이므로 닫힌 형태 ridge로 고정하고, 남은 12%의 상호작용만
학습한다.** 상호작용은 KEGG 경로가 정의하는 고정 관측 공간에서 일어나며 — 이것이
Koopman 사전 선택 문제에 대한 생물학적 답이다 — 교란마다 하나의 생성자 `A_a`를 배우고,
동시 섭동의 합성을 **반교환자** `A_aA_b + A_bA_a`로 둔다. 그 형태는 임의가 아니라
`exp(t(A+B))`와 가법적 예측의 차이에서 나오는 선두항이며, 동시 섭동이 갖는 교환 대칭과
일치한다. 변위는 생성자의 행렬 지수로 정확히 얻고, 선형 readout으로 유전자 공간에
되읽은 뒤, 평균 보존 hurdle head로 세포 집단을 실현한다. 설계상 **학습 전 모델은
베이스라인과 정확히 같고, 단일 교란의 예측은 학습이 끝날 때까지 베이스라인과 정확히
같다** — 후자는 발표된 학습 모델들이 모두 손해를 보는 블록이다.
