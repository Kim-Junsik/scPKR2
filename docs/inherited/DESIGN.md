## 0. 왜 새로 만드는가 — 네 개의 측정

### 0.1 v1은 닫힌 형태 ridge에 네 표 모두 진다

`scripts/baseline_l2.py`, 5 fold, 보고된 프로토콜(테스트 부분집합의 scanpy HVG 1,000개,
soft gate). Control L2가 논문 값과 0.2~2.5% 안에서 일치하므로 축척이 검증됨.

| | ridge_additive | scDFM | scPKFM(v1) | ridge − scDFM |
|---|---|---|---|---|
| Table 1 Norman additive | **1.669** | 1.704 | 1.957 | −0.035 |
| Table 2 Single | **1.416** | 1.619 | 1.754 | **−0.203** |
| Table 2 Double | 2.251 | **2.031** | 2.375 | **+0.220** |
| Table 3 ComboSciPlex | 1.858 | **1.657** | 2.138 | **+0.201** |

`ridge_additive`는 섭동별 효과 벡터를 학습 조건으로 ridge 적합해 `w_A + w_B`를 내는 것이
전부다. 상호작용 항도, 신경망도, flow도 없다. 결정론적이므로 seed 잡음이 없다.

### 0.2 학습 모델이 값어치를 내는 자리가 특정된다

| 블록 | scDFM이 ridge보다 | 조건 |
|---|---|---|
| Table 2 Double | **+0.220** | 조합, 단일이 홀드아웃 |
| Table 3 | **+0.201** | 조합, 단일이 홀드아웃 |
| Table 1 Double | −0.035 | 조합, 모든 단일이 학습에 있음 |
| Table 2 Single | **−0.203** | 홀드아웃 단일 |

**학습 모델의 이점은 "단일이 홀드아웃된 조합 블록"에만 있고, 두 번 모두 0.20이다.**
홀드아웃 단일에서는 오히려 0.20 손해다 — scDFM도 같이 손해를 본다.

### 0.3 잠재 병목은 제거 불가능한 세금이다

Table 3에서 디코더 한계(실제 섭동 세포를 인코딩→디코딩한 L2)가 **0.97**이다. 전체
2.138의 45%가 수송이 시작되기 전에 지불된다. `diagnose_train_gap.py`:

| 그룹 | 모델 L2 | 디코더 한계 | 수송 추가분 |
|---|---|---|---|
| 학습 단일 | 0.837 | 0.575 | 0.261 |
| 학습 조합 | 0.881 | 0.680 | 0.201 |
| 테스트 단일 | 2.669 | **1.348** | 1.320 |
| 테스트 조합 | 1.919 | **0.823** | 1.096 |

용량을 늘리면 나빠지고(rank-16 readout: 단일 2.57 → 3.94), KL을 올리면 붕괴한다
(Pearson Δ 0.012). **표현력 문제가 아니라 일반화 문제**이므로 잠재 오토인코더를 유지하는
어떤 설계도 이 0.97을 안고 간다. 유전자 공간 베이스라인은 0을 낸다.

### 0.4 신호의 88%가 가법이고, 비가법 부분만 남는다

순수 가법 ridge가 상호작용 항 없이 resid_R2 0.53(Norman fold 1)을 낸다. 명시적 상호작용
항(Lie 괄호, 섭동 임베딩 MLP)은 7개 설정·2개 백본에서 **5전 5패**했다.

## 1. 설계 원칙 — 위 네 측정의 직접적 귀결

1. **오토인코더를 두지 않는다.** 관측 함수를 학습하지 말고 고정한다 (0.3)
2. **가법 성분은 유전자 공간에서 닫힌 형태로 가져간다.** 신호의 88%를 학습하지 않는다 (0.4)
3. **모델은 비가법 잔차만 담당한다.** 목표 크기가 0.20으로 측정되어 있다 (0.2)
4. **단일 조건에는 손을 대지 않는다.** 구조적으로 보정 항이 0이 되게 한다 (0.2)
5. **ridge_additive가 출발점이 되게 한다.** 초기값에서 모델 예측 = ridge 예측 (0.1)

5번이 v1과의 결정적 차이다. **초기화 시점에 이미 1.669 / 1.416 / 2.251 / 1.858이고,
학습은 거기서 내려가는 방향으로만 움직일 수 있다.** v1은 2.138에서 시작해 0.49를 찾아야
했고 그중 0.97은 제거 불가능했다.

## 2. 모델

### 2.1 정의

```
관측 함수 (고정)     p = Φ(x) ∈ R^K
가법 항 (닫힌 형태)   Σ_{a∈S} w_a ∈ R^G          ridge, 학습 조건만
Koopman 연산자       A_a ∈ R^{K×K}               섭동마다, 저계수
합성 (|S| ≥ 2만)     B_S = Σ_{a<b∈S} (A_a A_b + A_b A_a)
경로 readout        W ∈ R^{G×K}, KEGG 엣지에서만 비영

예측
  Δx(S, x) = Σ_{a∈S} w_a  +  1[|S| ≥ 2] · W · B_S · Φ(x)
  x̂ = HurdleHead( x + Δx(S, x) )
```

### 2.2 각 조각의 근거

**`Φ` — 관측 함수를 KEGG로 고정한다.**
`Φ(x) = [M x ; S x]`. `M`은 KEGG 경로-유전자 소속 행렬을 행 정규화한 것(경로별 평균 발현),
`S`는 고정된 앵커 유전자 선택(섭동 대상 유전자 + 상위 분산 유전자). Norman에서
K ≈ 258 + 101, ComboSciPlex에서 약물은 유전자가 아니므로 경로 + 상위 분산.

Koopman 문헌의 중심 미해결 문제가 **"관측 함수 사전을 어떻게 고르는가"** 이고(eDMD의
dictionary selection), 지금까지의 답은 다항식·RBF·학습된 인코더였다. **KEGG는 그 문제에
대한 생물학적 답이다.** 데이터에서 짜내지 않으므로 과적합하지 않고, 고정이므로 재구성
손실이 없다.

v1과의 차이: v1도 KEGG를 썼지만 **attention을 게이팅하는 마스크**였다. 경로를 빼도
모델이 돌아갔고, 기록된 유일한 백본 비교에서 plain MLP가 앞섰다(0.3348 vs 0.1965).
여기서는 경로가 **관측 공간 자체**이므로 빼면 모델이 성립하지 않는다.

**`A_a` — 진짜 Koopman 연산자가 된다.**
고정된 사전 위의 선형 연산자는 교과서적 eDMD 설정이다. `dp/dτ = A_S p`의 흐름 맵은
`exp(τ A_S)`이고, `A_a`의 고유값·고유벡터가 **경로 좌표의 모드**다 — 스펙트럼 해석이
의미를 갖는다. v1의 각주("Koopman 형식이지 Koopman autoencoder가 아니다")가 필요 없다.

저계수와 공유 기저로 크기를 잡는다: `A_a = U diag(c_a) V + P_a Q_a`.
v1의 `SharedBasisGenerator`를 그대로 재사용한다.

**`B_S` — 반교환자가 올바른 대칭류다.**
생성자를 더해 적분하면 가법 흐름 맵과의 차이의 선두항이

```
exp(τ(A+B)) − (exp(τA) + exp(τB) − I) = (τ²/2)(AB + BA) + O(τ³)
```

즉 **반교환자**다. 수치 확인(scale 0.05/0.02/0.01에서 상대오차 3.5e-2 → 1.4e-2 → 7.0e-3,
스케일에 선형 감소 = O(τ³) 나머지). 교환자 `[A,B]`는 반대칭이므로 **순서 의존성**을
잡는 항이고, 동시 이중 섭동은 교환에 대칭이라 감독받을 신호가 없다.

**이것이 v1의 Lie 괄호 항이 5전 5패한 이유에 대한 정리 수준의 설명이다.** 그리고 이
문헌의 상호작용 항들이 대체로 같은 실수를 하고 있다.

구조적 성질:
- 섭동 쌍으로 인덱싱되는 파라미터가 없다 (`A_a`만)
- `a ↔ b` 교환에 대칭 → 순열 불변
- `|S| = 1`이면 항이 비어 있다 → **단일은 정확히 ridge 예측** (원칙 4)
- `A_a = 0` 초기화 → **초기 예측이 정확히 ridge_additive** (원칙 5)

**`W` — 비가법성이 경로를 통해 매개된다는 가설.**
`W`는 KEGG 엣지에서만 비영이다(nnz ≈ 39,574). 즉 **가법 효과는 유전자 공간 전체에서
자유롭지만, 비가법 보정은 경로 뼈대 위에서만 발생한다.**

이건 생물학적 주장이고 반증 가능하다: *섭동 간 상승·길항은 공유 경로를 통해 일어난다.*
Ablation은 같은 희소도의 무작위 뼈대다. 무작위가 같거나 더 좋으면 주장이 틀린 것이다.

**Hurdle 헤드 — 그대로 가져간다.**
데이터의 41%가 정확히 0이고, MSE 헤드는 0을 0.000% 만들며 표준편차의 24%를 잃는다.
`soft → sample`만으로 energy distance가 6.64 → 1.46이었다. DS가 v1이 가장 뒤지는 축이다.
`src/models/heads.py`를 재사용한다.

### 2.3 Flow Matching과 OT — 유지되고, 더 잘 맞는다

수송은 **경로 공간**에서 일어난다.

```
소스   p₀ = Φ(x_ctrl + Σ_a w_a)      가법 이동을 먹인 대조군 세포
타깃   p₁ = Φ(x)  ,  x ~ 조건 S
결합   minibatch UOT(p₀, p₁)         경로 공간에서
목표   v(p, t) = s(t) · B_S p        FM 손실 ‖v(p_t,t) − (p₁ − p₀)‖²
```

**경로 공간(258차원)의 OT가 유전자 공간(5,000차원)의 OT보다 조건이 좋다.** 미니배치 OT
plan은 참 plan의 추정치이고, 차원이 낮으면 같은 배치 크기로 훨씬 나은 추정이 된다. v1에서
"선명한 OT가 Norman은 돕고 ComboSciPlex는 해쳤다"는 미해결 문제의 원인이 표본 비율
(Norman 13% vs ComboSciPlex 2.4%)로 추정되는데, 차원을 20배 줄이면 그 축이 완화된다.

집단 통계 손실(endpoint, 조합 잔차)도 유지한다. 그리고 **장이 `p`에 선형이므로 흐름 맵이
정확히 행렬 지수다** — `torch.matrix_exp` 한 번으로 배치 전체를 정확히 적분할 수 있어,
v1의 계획 §10.1(유전자 공간 endpoint 손실, 측정 상한 0.20~0.26)이 비용 없이 가능해진다.
RK4가 필요 없다.

### 2.4 식별성 — 위험이 100%에서 12%로 옮겨간다

`A_a`는 조합을 통해서만 감독된다(`B_S`가 단일에서 0이므로). ComboSciPlex의 13개 약물처럼
학습 단일이 없는 경우에도 마찬가지다. 그러면 `A_a`가 식별되는가?

- 약물 `a`가 `b`, `c`와 조합에 나오면 `{A_a,A_b}`, `{A_a,A_c}` 두 방정식을 얻는다.
  전역 부호 반전(`모든 A → −A`)에 불변이고 그건 무해하다.
- 조합 하나에만 나오면 `A_b`가 보는 방향에서만 제약된다. 저계수·공유 기저가 정규화한다.

**핵심은 이것이 v1보다 나아진 점이다.** v1에서는 `u_a`가 변위 **전체**(가법 88% 포함)를
담당했고 ρ가 그 분할을 흐려서 식별 불가였다 — 측정: 홀드아웃 Dasatinib 단독이 참 shift와
반대 방향(cos −0.26, −0.31). 여기서는 가법 88%가 ridge에서 결정론적으로 오고,
**식별되지 않는 것은 12%뿐이다.**

## 3. 검증 가능한 주장 세 개와 ablation

논문의 기여가 곧 이 세 줄이고, 각각 빼면 무엇이 무너지는지가 정의된다.

| 주장 | Ablation | 예측 |
|---|---|---|
| **A. KEGG가 원칙적 Koopman 관측 사전이다** | (i) 같은 차원의 무작위 유전자군 뼈대 (ii) 같은 차원의 PCA 사전 (iii) 상위 K 분산 유전자 | KEGG > 전부. 특히 (ii)보다 나아야 한다 — 데이터에서 온 사전이 이기면 생물학이 하중을 받지 않는다 |
| **B. 비가법성은 경로 매개다** | `W`를 dense로 (G×K 전부 학습) | dense가 같거나 나쁘다. 좋으면 주장 철회 |
| **C. 동시 섭동 합성의 올바른 대칭은 반교환자다** | (i) 교환자 `[A_a,A_b]` (ii) 제약 없는 대칭 이선형 (iii) `(p, e_a, e_b)` MLP | 반교환자 ≥ 나머지, 교환자 ≈ 효과 없음. **v1의 5전 5패가 사전 증거다** |

추가로 반드시 실을 것:
- **베이스라인 행** — 네 표 전부에 `ridge_additive`를 싣는다. v1의 표에는 비어 있었고,
  리뷰어가 가장 먼저 묻는 자리다. 그리고 `ridge_additive`가 Table 1·2 Single에서
  scDFM과 동급 이상이라는 사실은 이 분야에 대한 발견이다.
- **잡음 바닥** — fold 분산(고정 베이스라인에서 resid_R2 0.47), seed 분산(ComboSciPlex
  L2 0.28, 측정됨). 단일 seed·단일 fold 수치가 서로 구분되지 않을 수 있다는 것이 이
  벤치마크에 대한 진술이다.
- **홀드아웃 단일에서 학습 모델이 ridge에 진다** (scPKFM 1.754, scDFM 1.619,
  ridge 1.416). scDFM도 겪으므로 특정 모델의 결함이 아니다.

실험 w8–w10. 수치는 조건별 보정(§3.2) 후의 L2이고, 규칙은 **학습 fold에서 적합해

**주장 A는 명시된 형태로 반증되고, 수정된 형태로 살아남는다.** 예측은 "KEGG > 전부,

처음부터 옳았다는 뜻이다. 효과의 비대칭이 그 근거다 — 백색화가 KEGG에 −0.0571,
PCA에 −0.0188로 **3배**를 준다. 단순한 분산 평준화였다면 둘에 비슷했어야 한다.

> 수정된 주장 A: **경로 사전은 유전자를 공유해 심하게 중복되어 있고, 그 중복을 푸는 데
> 저계수 연산자가 용량을 쓴다. 무상관화하면 데이터로 학습한 사전과 동등하다.**
> "생물학이 더 낫다"가 아니라 "생물학이 지지 않는다 — 올바로 조건화하면"이다. 외부에서
> 온 고정 사전이 데이터 사전과 동급이라는 것은 eDMD의 사전 선택 문제에 대한 진술이다.

**주장 B는 철회한다.** 예측은 "dense가 같거나 나쁘다. 좋으면 주장 철회"였고, dense가
좋다. 경로 매개 sparsity는 성능을 깎는다. 설계서가 미리 적어 둔 조건이므로 그대로
따른다. 관측 공간은 KEGG로 남고 readout만 dense가 된다 — 사전 주장(A)과 매개
주장(B)은 별개이고, 떨어진 쪽은 B다.

**주장 C는 약하게 유지된다.** s=1에서 이선형 +0.0098 ± 0.0160, 단순합 +0.0134 ±
0.0317로 둘 다 반교환자보다 나쁘고, 보정 후에는 단순합이 반교환자와 비긴다
(1.5290 대 1.5301). 교환자 팔은 아직 돌리지 않았다 — v1의 5전 5패가 사전 증거다.

### 3.2 네 번째 주장 — 잔차의 방향은 쓸 수 있고 크기는 보정해야 한다

사전에 없던 것이고 측정에서 나왔다. 조건별 최적 스케일은 `ρ‖e‖/‖r‖`이고 ρ가 조건마다
−0.51에서 +0.82까지 변하는데 모델은 한 가지 크기를 낸다. 전역 상수는 천장의 20 %만
가져가고, `s = clip(c‖r‖^−p, 0, 4)` 한 족이 76 %를 가져간다. 지수는 **고르는 것이 아니라
재는 것**이다 — `p=0`이 정확히 상수 규칙이고(실제 채점 경로에서 비트 단위로 확인),
combosciplex는 0.8–0.9를, norman:nval은 0.0을 골랐다. 즉 족이 도움이 안 되는 곳에서는
스스로 상수로 내려앉는다.

무엇이 신뢰도를 예측하는지도 측정했다. 제안했던 **경로 발자국 겹침은 실패했다**
(AUC 0.500). 작동하는 것은 모델 자신의 크기다 (AUC 0.82 / 0.94): 잔차가 작으면 코사인이
노이즈에 지배되어 부호가 동전 던지기가 된다.

### 3.3 아직 비어 있는 자리

- `composition=commutator`, `readout=random` — ablation 표의 대조군. 개선 후보가 아니다.
- Norman 두 표에서 백색화가 같은 효과를 내는지 (w11, w11b).
- 무작위 사전도 백색화하면 따라오는지. 따라온다면 A는 "조건화가 전부"로 더 약해진다.
  **이것은 반드시 돌려야 한다** — 돌리지 않으면 리뷰어가 묻는다.

## 4. 파라미터 예산

설계 시점의 추정이 아니라 **실측**이다 (ComboSciPlex, `G=5,000`, `K=418` = KEGG 경로
162 + anchor 256, `P=17`).

| | readout=kegg (설계 시점) | **readout=dense (w8–w10에서 채택)** |
|---|---|---|
| `A_a` 연산자 | 84,144 | 84,144 |
| `W` readout | 4,504 | **2,090,000** |
| Hurdle 헤드 | 15,000 | 15,000 |
| **학습 파라미터 합** | 103,648 | **2,189,144** |
| `w_a` (ridge, 학습 안 함) | 85,000 | 85,000 |

**설계 시점의 115 K는 더 이상 맞지 않는다.** 주장 B를 철회하고 readout을 dense로 바꾸면서
(§3.1) `W`가 `G × K` 전체가 되어 2.09 M이 되었고, 그것이 학습 파라미터의 95%다. 연산자와
헤드는 그대로다.

비교로, v1은 **인코더 하나만** 5.2 M이었고 거기에 더해 ρ 36 K와 약물당 46 K의 연산자를
적합했다. 지금 모델은 전체가 2.19 M이고, 그중 실제로 상호작용을 담당하는 `A_a`는 84 K에
불과하다 — **나머지는 418차원을 5,000차원으로 되읽는 선형 사상 하나**이고, 그 크기는
용량이라기보다 유전자 수가 정하는 값이다.

## 7. 위험

| 위험 | 완화 | 실패 시 |
|---|---|---|
| **경로 뼈대가 너무 거칠다.** KEGG가 Norman 대상 101개 중 48개만 덮는다 | `Φ`와 `W`에 앵커 유전자 좌표를 추가. 대상 유전자는 반드시 관측 공간에 있어야 한다 | 주장 A가 약해지고 "고정 사전"이 "부분적으로 고정"이 된다 |
| **비가법 잔차가 학습 불가능하다.** 0.20이 잡음일 수 있다 | 게이트 1이 4주차에 잡는다 | 성능 논문 불가. 0.2절의 진단은 그대로 남아 분석 논문의 재료가 된다 |
| **`A_a`가 조합 하나로는 식별 안 된다** | 공유 기저 + 저계수. 그리고 위험이 12%에만 걸린다 | 조합 1회 약물에서 성능이 안 나옴 → 블록별로 보고 |
| **`ridge_alpha`가 미조정이다** (config: PROVISIONAL) | 학습 조합으로 내부 CV. 베이스라인이 더 강해질 수 있다 | 출발점이 올라가므로 오히려 좋다 |
| **seed·fold 분산이 효과보다 크다** | 보고 수치를 3 seed 평균으로. 사전 등록 규칙 유지 | 어떤 주장도 못 함 — 그래서 3–4주차에 먼저 잰다 |

| 데이터셋별 학습 | 유지 |

| 성능을 올린다 | 게이트 2가 그 판정 |
