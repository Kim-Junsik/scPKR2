# scPKR2 설계 — KEGG를 부드러운 사전지식으로: 지도 링크 뼈대 + 벌점 잔차

2026-10-19. `docs/DESIGN_GRAPH.md`(단단한 마스크, 닫힘)의 다음 단계. **결과를 보기 전에 쓴다.**

---

## 0. 왜 이 설계인가

KEGG 구조를 단단한 제약으로 넣은 세 실험이 모두 무작위와 구분되지 않았다(FINDINGS 21~23).

| 자리 | KEGG | 무작위 |
|---|---|---|
| 입력 좌표의 유전자 묶음 (E) | 1.6837 | 1.6805 |
| 생성자 연결, 공유 유전자 (K/P) | 1.6919 | 1.6664 |
| 생성자 연결, KEGG 지도 링크 (KM/PM) | 1.9422 | 1.9101 |

지도 링크는 KEGG가 직접 그린 큐레이션된 연결이지만, 단독으로는 너무 성겨(경로 간 밀도 3.2 %)
ridge보다도 나빠졌다. 단단한 제약은 데이터가 필요로 하는 KEGG 밖의 연결을 하나도 허락하지
않는다.

이 설계는 KEGG를 **제약이 아니라 사전 확률**로 쓴다.

```
A_a = ( G ⊙ A_a^K )  +  A_a^W            손실 += λ Σ_{a ∈ S} ‖A_a^W‖²_F
       KEGG 뼈대           전체 연결 잔차
```

KEGG 연결 위의 결합은 벌점 없이 쓰고, 그 밖의 결합은 데이터가 벌점을 이길 만큼 필요로 할
때만 쓴다. 살아남은 KEGG 밖 결합은 "데이터가 지지하는, KEGG에 없는 경로 간 연결" 후보다.

정확도(L2)는 세 번 연속 KEGG와 무작위를 구분하지 못했고, 잔차가 있으면 더 둔해진다(잔차가
틀린 뼈대를 보정하므로). 그래서 생물학 판정의 1차 지표는 **그래프 밖으로 나간 결합의 비율**이다.

> 같은 벌점에서, KEGG 뼈대가 같은 모양의 무작위 뼈대보다 그래프 밖 보정을 덜 필요로 하는가?

KEGG의 연결이 데이터가 실제로 쓰는 결합과 맞는다면 그렇다.

## 1. 모델

2단계 생성자 모델에서 생성자만 바뀐다.

```
A_a^K = U_K diag(c_a^K) V_K + P_a^K Q_a^K        뼈대 가지 (공유 32모드 + 고유 rank 4)
A_a^W = U_W diag(c_a^W) V_W + P_a^W Q_a^W        잔차 가지 (같은 계수)
A_a   = ( G ⊙ A_a^K + A_a^W ) ⊙ R                R: 상수 행을 0으로 하는 기존 행 마스크
B_S   = Σ_{a ∈ S} A_a,   dp = (exp(B_S) − I) p    이하 2단계 그대로
```

- **뼈대 그래프 G는 KEGG 지도 링크다**(`DESIGN_GRAPH.md` 10절, `generator_mask_source=maplink`).
  공유 유전자 그래프가 아닌 이유: 그것은 유전자 목록에서 파생한 대용품이고, 큐레이션된 지식은
  지도 링크다. 앵커-경로 소속, 대각, 열린 상수 열은 그대로다.
- **잔차 가지는 조밀하다**(마스크 없음). 행 마스크만 받는다.
- **α를 따로 두지 않는다.** α를 학습하면 잔차 가지가 모든 것을 가져가 뼈대가 무의미해진다.
  잔차의 크기는 벌점 λ 하나로 조절한다.
- **벌점은 단계마다 그 조건의 교란에 대해** `λ Σ_{a ∈ S} ‖A_a^W‖²_F`(행 마스크 적용 후)다.
  학습 루프가 한 단계에 한 조건을 다루므로, 자주 나오는 교란이 더 자주 벌점을 받는다.
- 초기값: 두 가지 모두 2단계와 같다(작은 난수, `c = 1`). 판독 0에서 출발하므로 학습 전 모델은
  여전히 대조군이다.
- 학습 설정: D 설정(관측 공간 손실 없음, 250 에폭), **백색화 없음**(마스크가 경로를 뜻하려면
  필요하다, `DESIGN_GRAPH.md` 2.4).

설정 키 (구현 시):

| 키 | 값 | 기본 |
|---|---|---|
| `model.generator_residual` | 잔차 가지를 둘지 | `false` (2단계 그대로) |
| `model.generator_residual_penalty` | λ | 검증으로 정함 (H0) |

뼈대 쪽은 기존 키(`generator_mask`, `generator_mask_source`)를 그대로 쓴다. 잔차가 켜져 있고
마스크가 `none`이면 거부한다(뼈대 없는 잔차는 두 배 크기의 조밀한 모델일 뿐이다).

## 2. 실험

| 실험 | 뼈대 | 잔차 | 질문 |
|---|---|---|---|
| **KH** | KEGG 지도 링크 | 있음 | 주 모델 후보 |
| PH | 지도 링크, 블록 안 라벨 순열 (시드마다 다른 순열) | 있음 | 같은 모양, 틀린 뼈대 (H2) |
| RH | 데이터 상관 그래프, 블록별 간선 수는 지도 링크와 같음 | 있음 | KEGG가 데이터 상관 이상인가 (부차) |
| D | 없음 (조밀, zca) | — | 정확도 기준 (`s2fin_*`, `s2D_*`) |

P와 R의 구성은 `DESIGN_GRAPH.md` 5절 그대로다.

## 3. 데이터를 나눠 쓰는 방식

fold 3은 지금까지의 개발(2단계 비교 실험, 그래프 실험 전부)에 반복해서 쓰였다. 그 위에서 변형을
고르면 우연히 문턱을 넘은 것을 고를 위험이 있다. 그래서:

| 단계 | 데이터 | 쓰임 |
|---|---|---|
| H0 (λ 선택) | norman 검증 분할 (fold 0의 학습 double 15개) | λ 하나를 고른다 |
| **판정 (H1, H2)** | **fold 0, 1, 2, 4** × 시드 3개 | 고르는 데 쓰지 않은 데이터 |
| 참고 | fold 3 | 보고는 하되 판정에 쓰지 않는다 |

한계: 5 fold는 서로 겹치는 무작위 70/30 추출이라(`src/data/splits.py`), 검증 분할의 double 일부는
fold 1, 2, 4의 테스트에도 들어 있다. 검증이 고르는 것은 λ 하나(그리고 이전에 학습 길이 하나)뿐이므로
누수는 그 스칼라 하나를 통한 것에 그친다. 이 한계는 논문에도 적는다.

## 4. 가설과 판정 조건

**H0. λ는 검증 분할에서 고른다.**
λ ∈ {10⁻³, 10⁻², 10⁻¹, 1, 10}, KH와 PH 각각 시드 0 (run 10개). **두 실험의 검증 L2 평균이 가장 낮은
λ**를 고른다. KEGG 쪽 L2만으로 고르면 KH에 유리한 λ가 뽑히므로 두 쪽을 함께 본다. 고른 값이 격자의
끝이면 그쪽으로 한 자리를 더 늘려(검증에서만) 다시 고른다.

**H1. 정확도.** 판정 fold 4개에서 KH의 L2 평균이 D의 같은 fold 평균 + 0.02 이하여야 KH가 주 모델이
될 수 있다. D의 숫자는 `stage2_folds.sh`의 `s2fin_f{0,1,2,4}_s*`다.

**H2. 생물학 (1차 판정).** 각 학습된 모델에서 그래프 밖 비율을 잰다.

```
s = Σ_a ‖ (1 − G) ⊙ A_a ‖²_F  /  Σ_a ‖ A_a ‖²_F
```

`A_a`는 최종 생성자(뼈대 + 잔차), K×K 부분(상수 열 제외 — 그 열은 두 실험 모두 열려 있다), 합은 학습
교란 전체에 대해, G는 그 run 자신의 뼈대 그래프다. **같은 fold·같은 시드의 (KH, PH) 12쌍 중 10쌍
이상에서 KH의 s가 낮으면 통과**한다(한쪽 부호 검정, 우연일 확률 0.019).

**H2'. 정확도에서의 기여 (2차, 보고만).** 12쌍의 L2 차이(PH − KH)의 평균과 표준편차. 0.02를 넘으면
"KEGG 뼈대가 정확도도 높인다"를 함께 쓴다. 넘지 않아도 H2의 판정은 바뀌지 않는다.

**H3. 데이터 상관과의 비교 (부차, 기술만).** RH를 판정 fold 4개 × 시드 0으로 돌려 s와 L2를 KH와
나란히 적는다. 지도 링크 간선의 88 %가 공유 유전자 그래프 안에 있고, 유전자를 공유하는 경로는 좌표가
상관된다. 그래서 KH의 s가 낮은 이유가 "생물학"이 아니라 "상관된 좌표끼리의 결합이 싸다"일 수도
있다. RH의 s가 KH와 같거나 낮으면 주장은 "KEGG가 데이터를 맞추지 않고도 데이터의 상관 구조를
담는다"로 약해진다.

## 6. 구조가 보장하는 것 (테스트)

| | 성질 |
|---|---|
| P1 | 잔차가 꺼져 있으면 지금의 마스크 모델과 비트 단위로 같다 |
| P2 | λ = 0이고 뼈대가 무엇이든, 잔차 가지만으로 그래프 밖 칸이 0이 아닐 수 있다 (우회 경로가 실제로 열려 있다) |
| P3 | 잔차의 그래프 밖 칸은 학습 중 벌점의 기울기를 받는다; 뼈대 가지는 받지 않는다 |
| P4 | 대조군 정확성, 양수성, 순서 불변 (2단계 G1~G3) 유지 |
| P5 | `s`의 계산: 그래프 밖 칸만 가진 생성자는 1, 그래프 안 칸만 가진 생성자는 0 |
| P6 | 잔차가 켜져 있고 마스크가 `none`이면 거부된다 |

## 8. 논문에서의 위치

최종 방법은 "KEGG 지도 링크 뼈대 + 벌점 잔차 생성자"이고, 지금까지의 실험은 모두 ablation 표에
들어간다. 숨기는 행은 없다.

| ablation 행 | 출처 |
|---|---|
| 사전지식 없음 (조밀 생성자) | D |
| 입력 좌표의 유전자 묶음만 무작위 | E (FINDINGS 21) |
| 단단한 마스크: 공유 유전자 그래프 / 그 순열 | K / P (22) |
| 단단한 마스크: 지도 링크 / 그 순열 | KM / PM (23) |
| **부드러운 사전: 지도 링크 / 그 순열 / 상관** | **KH / PH / RH (이 문서)** |

논문에는 방법과 결과를 쓴다. 연구의 시간 순서("처음부터 이 가설이었다")에 대한 진술은 쓰지 않는다.

**말할 수 있는 것 (H2 통과 시)**

- 데이터가 필요로 하는 경로 간 결합을, KEGG가 그린 연결이 같은 모양의 무작위 연결보다 더 많이
  설명한다(그래프 밖 비율, 12쌍 중 n쌍).
- 벌점을 이기고 남은 KEGG 밖 결합의 목록 — 데이터가 지지하는 새 연결 **후보**로 제시한다.

**말할 수 없는 것**

- H2'가 0.02를 넘지 않으면 "KEGG가 정확도를 높인다".
- H3에서 RH가 KH와 같거나 나으면 "KEGG가 데이터 상관 이상의 정보를 준다".
- 남은 KEGG 밖 결합이 실제 생물학적 상호작용이라는 것. 검증되지 않은 후보다.
- 결합의 방향(상류/하류). 그래프는 양방향으로 다룬다.
