# scPKR2 설계 — 하이브리드 관측 좌표와 확률적 Koopman FM

2026-10-21. **결과를 보기 전에 쓴다.** 지식 인코더(`DESIGN_ENCODER.md`)와는 독립이다. 둘 다 통과하면
마지막에 합친다.

---

## 0. 왜 이 설계인가

두 가지 요구가 있다.

1. **학습된 표현.** 세포 좌표가 고정된 KEGG 좌표뿐이라 모델의 표현력이 사전지식에 묶여 있다. KEGG는
   무작위 유전자 묶음과 구분되지 않았다(FINDINGS 21).
2. **흐름 학습(FM)의 역할.** FM은 지금 꺼져 있다. 켜도 끄도 평균 L2가 같아서(B 1.6837, D 1.6852,
   FINDINGS 21) 미리 정한 규칙대로 뺐다. 그러나 FM이 평가된 지표는 집단 평균의 L2 하나뿐이었다.

FM이 아무 일도 하지 않은 이유는 측정에 이미 나와 있다.

| 측정 | 출처 |
|---|---|
| FM 손실이 학습 내내 1.79 근처에서 움직이지 않음 | FINDINGS 18 |
| 세포 짝짓기를 무작위로 해도 L2 +0.013 | FINDINGS 25 |

대조군 세포와 처리군 세포는 서로 다른 세포다. 짝지은 두 세포의 차이(FM의 정답 속도) 대부분은 교란
효과가 아니라 **세포 간 개인차**이고, 결정론적 FM은 그 잡음을 정답으로 맞추려 한다.

이 설계는 두 가지를 바꾼다.

- **하이브리드 관측 좌표.** p = [Φ_KEGG(x); z_θ(x); 1]. 고정된 생물학 좌표에 학습된 잠재 좌표를 이어 붙인다.
- **확률적 Koopman FM.** 짝지은 두 세포 사이 경로에 브라운 다리 잡음을 넣는다. 개인차를 잡음으로
  명시해서, 생성자가 잡음 대신 평균적인 흐름을 배우게 한다.

학습된 좌표가 들어가면 FM에는 고유한 역할이 생긴다. 유전자 손실은 디코더를 거친 결과만 보지만, FM은
"잠재 좌표가 교란 아래에서 어떻게 움직이는가"를 직접 가르친다.

## 1. 모델

```
p(x)  = [ Φ_KEGG(x) ; z_θ(x) ; 1 ]            K = 467 (경로 + 앵커) + d_z (64) + 상수 1
z_θ   = LN_noaffine( MLP_θ(x) )               x: log1p 발현 전체, MLP 은닉 256
A_a   = U diag(c_a) V + P_a Q_a               (K+d_z+1)×(K+d_z+1), 마지막 행 0
dp    = (exp(B_S) − I) p,   B_S = Σ A_a       2단계 그대로
mu    = x exp(W_u dp) + softplus(v0 + W_v dp) 2단계 그대로 — 디코더는 움직인 양만 읽는다
```

- **이어 붙이기, 더하기 아님.** 더하면 KEGG 좌표가 섞여 경로 이름으로 읽을 수 없게 된다.
- **재구성 한계가 없다.** 이전 모델(scPKFM)은 잠재 공간에서 세포를 복원해야 해서 재구성 오차가 전체
  오차의 45 %였다(`models/observables.py` 머리말). 여기 디코더는 dp만 읽어 원래 세포 x에 적용하므로
  복원이 필요 없다. z는 좌표를 늘릴 뿐이다.
- **붕괴 방지.** z에 FM 손실을 걸면 z를 0으로 줄여 손실을 낮추는 길이 열린다. 세포마다 z를 정규화한다
  (LayerNorm, 학습 가능한 배율 없음): 각 세포의 z는 64개 차원에 걸쳐 평균 0, 분산 1이므로 0으로 줄어들 수
  없다.
  > **정정 (2026-10-21, 구현 전).** 처음 판은 배치 정규화였다. 학습 중에는 대조군 묶음과 처리군 묶음이
  > 따로 들어오므로, 묶음마다 평균 0으로 맞추면 두 집단의 평균 차이 — 교란 효과 자체 — 가 지워진다.
  > 세포 단위 정규화는 묶음 구성과 무관하고, 학습과 평가에서 같은 함수다.
- **짝짓기는 KEGG 좌표에서만.** OT 결합은 지금처럼 Φ_KEGG에서 계산한다. 학습 중에 바뀌는 z로 짝을
  지으면 짝이 움직이는 표적이 된다.
- 백색화(ZCA)는 KEGG 블록에만 건다(2단계 D 설정 그대로). z는 배치 정규화로 이미 표준화되어 있다.

## 2. 확률적 Koopman FM

짝지은 (p0, p1)에 대해, 시간 t ~ U(0.01, 0.99), ε ~ N(0, I):

```
p_t    = (1 − t) p0 + t p1 + σ sqrt(t(1 − t)) ε                    브라운 다리 보간
u_t    = (p1 − p0) + σ (1 − 2t) / (2 sqrt(t(1 − t))) ε             그 조건부 속도
L_FM   = ‖ B_S p_t − u_t ‖²   (관측 좌표 블록 전체, 상수 좌표 제외)
```

- 브라운 다리를 기준 과정으로 하는 확률적 보간이다(Tong 등 2024의 SB-CFM과 같은 보간과 목표).
- 모델 속도는 2단계 그대로 시간에 무관한 선형장 B_S p다. 따라서 이 손실은 "확률적 보간의 속도장을
  Koopman 선형장들 중에서 가장 잘 근사하는 것"을 찾는다. σ = 0이면 지금의 결정론적 FM과 같다.
- 끝점 손실(‖exp(B_S) p0 − p1‖²)은 B 설정 그대로 함께 쓴다.
- 손실 가중치는 2단계 B 설정 그대로다(FM 1, 끝점 3, 유전자 평균 10).

---

## 3. 실험

2 × 3 요인 설계. 관측 좌표 {KEGG, KEGG ⊕ z} × FM {없음, 결정론적, 확률적}.

| 실험 | 관측 좌표 | FM | 출처 |
|---|---|---|---|
| D | KEGG | 없음 | 기존 run (`s2fin_*`, `s2D_*`) |
| B | KEGG | 결정론적 (σ = 0) | 새로 |
| S | KEGG | 확률적 | 새로 |
| L | KEGG ⊕ z | 없음 | 새로 |
| LF | KEGG ⊕ z | 결정론적 | 새로 |
| **LS** | **KEGG ⊕ z** | **확률적** | **새로 — 주 모델 후보** |

| 단계 | 데이터 | 쓰임 |

## 5. 지표

- **L2** (평균 정확도): `compare_to_ridge.py`, soft, 세포 평균 한계 — 지금까지와 같음.
- **에너지 거리** (분포 정확도): `train.py`의 평가가 `results.json`에 적는 `edist_rel` — 예측 세포 집단과
  실제 처리군 세포 집단의 에너지 거리를, 대조군과 처리군의 거리로 나눈 값. 모든 실험이 같은 절차로
  계산한다. **FM의 기여는 평균이 아니라 분포에서 나타날 것으로 예상하므로 FM 판정의 1차 지표다.**
- 판정 뒤 주 모델은 발표 프로토콜의 6개 열로 따로 채점한다.

## 6. 가설과 판정 조건

**H0. σ는 검증 분할에서 고른다.**
LS를 σ ∈ {0.1, 0.3, 1.0}, 시드 0으로 돌린다(run 3개). 검증 L2가 최저값에서 0.02 안에 드는 σ들 중
`edist_rel`이 가장 낮은 것을 고른다. 고른 σ를 S에도 쓴다. 고른 값이 격자 끝이면 그쪽으로 한 자리 더
늘려(0.03 또는 3.0) 다시 고른다.

판정은 같은 fold·같은 시드의 12쌍으로 한다. "12쌍 중 10쌍 이상"은 한쪽 부호 검정 p = 0.019다.

**F1. FM이 기여한다 (사용자의 핵심 질문).**
LS 대 L: `edist_rel`이 12쌍 중 10쌍 이상에서 낮고, **그리고** L2 평균이 0.02 넘게 나쁘지 않으면 통과.
통과하면 "확률적 Koopman FM이 예측 분포를 개선한다"고 쓸 수 있다.

**F2. 확률적 형태가 필요하다.**
LS 대 LF: 같은 기준. 통과하면 "결정론적 FM이 아니라 확률적 FM이어야 한다"를 쓸 수 있고, 이것이 FM이
지금까지 효과가 없었던 이유(세포 간 잡음)에 대한 설명이 된다.

**O1. 학습된 잠재 좌표가 기여한다.**
LS 대 S: L2 평균이 0.02 넘게 낮거나, L2가 12쌍 중 10쌍 이상에서 낮으면 통과.

**보고만:** 6개 실험의 L2와 `edist_rel` 전체 표, fold 3 결과, 학습된 z와 KEGG 좌표의 상관.

## 10. 말할 수 있는 것과 없는 것

**말할 수 있는 것**
- F1 통과: 확률적 Koopman FM이 예측 세포 분포를 개선한다(에너지 거리, 12쌍 중 n쌍).
- F2 통과: 결정론적 FM은 세포 간 잡음에 막혀 기여하지 못하고, 확률적 보간이 그것을 푼다.
- O1 통과: 고정된 생물학 좌표에 학습된 좌표를 더하면 정확도가 오른다.

**말할 수 없는 것**
- F1이 실패하면 "FM이 기여한다".
- 학습된 잠재 좌표의 생물학적 의미. KEGG 블록만 경로 이름으로 읽힌다.
- 이 FM이 시간에 따른 세포 궤적을 재현한다는 것. 데이터에 시간이 없다.
